# 本地队列、视频导出与工程稳定化设计

## 目标

在不考虑 EXE 打包的前提下，将 Dreamina CLI 批量工具整理为长期运行的纯本地开发环境，解决绑定资产未作为参考发送、队列只能严格串行、错误处理过于粗糙、视频导出依赖手输路径、重复路由和工程结构未完全拆分等问题。

## 运行架构

本地环境由三个普通进程组成：

1. Vite 前端。
2. FastAPI 接口服务。
3. 独立队列 worker：`python -m backend.app.queue_worker`。

FastAPI 只处理项目、分镜、资产、队列控制和查询接口。worker 通过 SQLite 读取持久化任务并调用 Dreamina CLI。二者不共享进程内状态。

SQLite 开启 WAL 和 busy timeout。worker 使用数据库租约和心跳保证同一数据目录只有一个有效调度器。worker 或 API 重启后，已有 `submit_id` 的任务继续轮询，没有 `submit_id` 的中断任务进入可重试状态，禁止无依据重复提交。

## 全局队列设置

“即梦设置”新增队列调度区域，配置保存在 SQLite：

| 配置 | 默认值 | 合法范围 |
| --- | ---: | ---: |
| 提交间隔 `submit_interval_seconds` | 5 秒 | 1-300 秒 |
| 最大在途任务 `max_in_flight` | 3 条 | 1-50 条 |
| 结果轮询间隔 `result_poll_interval_seconds` | 30 秒 | 5-300 秒 |
| CLI 首次等待 `cli_initial_poll_seconds` | 3 秒 | 1-60 秒 |
| 自动重试次数 `max_retry_attempts` | 5 次 | 0-20 次 |
| 重试基础间隔 `retry_base_seconds` | 30 秒 | 5-600 秒 |

用户后期可以直接设置为提交间隔 3 秒、最大在途 10 条。界面提示高并发可能触发平台限流或队列满，但不把默认值写死为选项。

## 队列状态机

队列状态为：

- `waiting`：等待领取。
- `submitting`：worker 已取得租约，正在调用 CLI。
- `polling`：平台已受理并返回 `submit_id`，等待结果。
- `retry_wait`：可恢复错误，等待 `next_attempt_at`。
- `blocked`：登录失效、积分不足等全局阻塞。
- `completed`：结果已下载并创建候选视频。
- `failed`：永久失败或超过重试上限。
- `canceled`：用户取消，不再出现在默认队列列表。
- `orphaned`：旧任务缺少 `submit_id`，需要人工确认后重试。

worker 每轮先轮询到期的在途任务，再判断 `in_flight < max_in_flight` 和提交间隔是否满足，最后领取一条等待任务。提交成功得到 `submit_id` 后立即转为 `polling`，不等待该视频完成才提交下一条。

## 错误分类

CLI 输出解析增加明确分类：

- `queue_full`、`rate_limited`、`provider_busy`：全局提交退避，任务进入 `retry_wait`。
- `network_error`、`timeout`：任务有限重试，其他已提交任务继续轮询。
- `auth_required`、`credit_insufficient`：任务与新提交进入 `blocked`，队列页面显示阻塞原因。
- `invalid_argument`、`model_unsupported`、`missing_reference`：当前任务永久失败，继续下一条。
- 未知错误：按有限重试处理，超过上限后失败。

指数退避使用 `retry_base_seconds * 2^(attempt-1)`，并限制最大等待时间为 30 分钟。

## 参考资产组装

队列项继续保存提交时的资产快照，避免后续修改绑定影响已排队任务。worker 通过独立的参考构建器将快照转换为 CLI 参数：

1. 角色图片，按绑定顺序。
2. 场景图片，按绑定顺序。
3. 道具图片，按绑定顺序。
4. 已开启 `voice_enabled` 的角色音色，按角色绑定顺序。

所有路径去重并验证存在。绑定资产存在时统一使用 `multimodal2video`；显式首帧且没有绑定资产时才使用 `image2video`；没有任何参考文件时使用 `text2video`。

提交前严格验证图片最多 9 张、视频最多 3 段、音频最多 3 段、音频 2-15 秒，并在错误中列出超限或缺失的资产名称，不静默截断。

文字提示词和二进制参考并行保留。最终提示词仍由视频模板、风格提示词、角色、场景、道具和分镜提示词渲染；图片和音频路径作为独立 CLI 参数发送。

## 视频导出

纯本地模式通过 FastAPI 调用系统目录选择器，不再要求用户手工输入路径。

- 批量导出：用户选择目标文件夹，后端创建“剧本名+年月日时分”子目录，复制选中分镜的默认视频并命名为 `分镜N.<扩展名>`。
- 单条下载：分镜右侧预览区域提供独立“下载视频”按钮，选择文件夹后保存为 `分镜N.<扩展名>`。
- 本地候选使用文件复制；远程候选使用流式下载。
- 单条文件重名时返回冲突，前端二次确认覆盖；批量目录重名时追加序号。
- 目录选择接口仅接受本机回环地址调用，并通过互斥锁避免同时弹出多个选择框。
