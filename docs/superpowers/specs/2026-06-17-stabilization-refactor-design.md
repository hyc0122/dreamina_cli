# 即梦 CLI 批量工具稳定化重构设计

## 目标

本次重构优先解决稳定性、维护性和数据安全问题，同时补齐用户明确要求的批量删除、资产预览模式、队列恢复、CLI 输出分层、测试链路和使用手册。所有既有 API 对外路径尽量保持兼容，避免前端和 EXE 发布包出现大面积 404。

## 范围

- 分镜提示词支持批量删除。
- 资产管理支持批量删除，但已经绑定到任意分镜的资产禁止删除，并返回绑定分镜序号。
- 资产管理支持小图标、大图标、预览三种布局；未选中资产时右侧只显示轻量空态。
- 运行数据、源码、构建缓存、发布产物分开目录。
- `jimeng_api.py` 拆为按业务分类的接口模块，并保留中文注释。
- `jimeng_storage.py` 拆为按数据域分类的存储模块，并保留 `JimengStore` 兼容入口。
- CLI 输出解析拆为单独 parser/errors/models/capabilities。
- 队列从轻量请求驱动 worker 增强为 SQLite 持久队列 + 启动恢复。
- 前端页面按页面和业务组件分层。
- 补齐后端、前端、打包和文档验证链路。
- 使用手册详细说明 CLI 返回、缓存位置和常见错误。

## 数据和目录

开发环境默认数据目录迁移为 `runtime_data/`，用于存放 SQLite、上传文件、下载视频、CLI profile、日志和缓存。构建临时文件进入 `build_cache/`，发布包进入 `releases/`。EXE 运行时仍使用 EXE 同级 `data/`，保持普通用户易理解。

需要提供兼容：如果检测到旧的 `backend/data/jimeng.sqlite3`，后端仍可读取；后续再提供一键迁移脚本。

## 后端接口拆分

保留 `/jimeng` 前缀，新增 `backend/app/api/router.py` 聚合业务路由：

- `projects.py`：剧本项目接口。
- `shots.py`：分镜接口，包含导入、批量替换、批量删除、时长检测。
- `assets.py`：资产接口，包含批量上传、批量删除、导入导出、生图。
- `bindings.py`：分镜资产绑定接口。
- `queue.py`：队列接口。
- `candidates.py`：视频候选接口。
- `settings.py`：CLI 设置、多账号、登录、积分、能力检测。
- `prompt_presets.py`：全局视频生成模板和图片提示词模板。

每个接口文件开头必须有中文注释，说明该文件负责的业务边界。

## 存储拆分

新增 `backend/app/storage/`：

- `schema.py`：SQLite 建表、迁移和列补齐。
- `store.py`：`JimengStore` 聚合入口，保持既有调用兼容。
- `projects.py`、`shots.py`、`assets.py`、`bindings.py`、`queue.py`、`candidates.py`、`accounts.py`、`presets.py`：按数据域拆分。
- `paths.py`：路径校验、安全删除、输出目录计算。

第一阶段允许 `store.py` 组合 mixin，降低一次性重构风险。

## 删除规则

资产删除必须先检查绑定关系。只要资产绑定到任意分镜，单个删除和批量删除都必须拒绝该资产，并返回绑定分镜序号，例如：`资产「许禾」已绑定：分镜1、分镜3，请先解除绑定后再删除。`

批量删除时采用“全有或全无”规则：只要选中资产里存在已绑定资产，本次批量删除整体失败，并返回所有被绑定资产的分镜序号。这样避免用户误以为已全部删除。

分镜批量删除允许删除选中分镜，删除后重新排序分镜序号。分镜删除会级联删除该分镜的绑定和候选视频记录，文件清理仍按现有安全路径规则执行。

## 队列机制

队列状态扩展为：

- `waiting`
- `running`
- `polling`
- `completed`
- `failed`
- `canceled`
- `orphaned`

应用启动时执行恢复：

- `running` 且有 `submit_id`：改为 `polling`，继续查询结果。
- `running` 且没有 `submit_id`：改为 `orphaned`，提示用户可重试。
- `polling`：继续查询结果。

队列项保存账号 ID、最终提示词快照、参数快照、CLI 命令、raw output、错误分类和重试次数。

## CLI 输出解析

新增 CLI 分层模块：

- `cli/dreamina.py`：负责执行命令。
- `cli/parser.py`：负责解析 raw output。
- `cli/errors.py`：负责错误分类。
- `cli/models.py`：负责返回结构。
- `cli/capabilities.py`：负责模型、画幅、分辨率和限制说明。

前端展示错误时优先显示错误分类和可读说明，再允许展开 raw output。

## 前端布局

页面按 `pages/` 拆分：首页、剧本列表、分镜工作台、资产管理、队列、生成记录、设置。复杂页面再按业务拆子组件。

资产管理新增视图模式：

- 小图标：紧凑网格。
- 大图标：图片检查。
- 预览：左侧列表，右侧详情。

没有选中资产时，右侧只显示图标空态，不显示大预览和表单。
