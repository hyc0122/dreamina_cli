# 资产生图全局模型设置设计

日期：2026-06-20

## 背景

资产管理页当前有两类生图设置：

- 顶部“生图设置”弹窗保存资产生图的全局提示词、类型前缀、默认画幅和分辨率。
- 单个资产详情和新建资产弹窗仍提供“生图模型”下拉，并把单资产表单里的模型值用于单个资产 AI 生图。

这会让资产生图模型选择分散到每个资产上，用户需要重复选择，也容易和“大模型设置”里维护的图片模型列表混淆。

## 目标

资产管理增加全局生图模型设置。单个资产生图时不再选择模型，而是统一使用资产管理全局设置里的模型。单个资产详情只显示当前全局选择的模型，方便用户确认本次会调用哪个模型。

## 范围

本次只调整资产管理页的大模型资产生图体验：

- 资产管理“生图设置”弹窗增加全局生图模型选择。
- 单个资产详情移除“生图模型”下拉，改成只读显示当前全局模型。
- 新建资产弹窗移除“生图模型”下拉，避免新资产继续携带误导性的单资产模型选择。
- 单个资产 AI 生图和批量生图都使用全局模型设置。
- 保留资产数据里的 `image_model` 字段用于兼容旧数据、导入导出和即梦 CLI 历史字段，不做数据库迁移或字段删除。

不调整分镜视频生成模型、即梦 CLI 图片模型校验、大模型供应商配置页面。

## 设计

### 全局设置

扩展 `AssetImageSettings`，增加一个资产生图模型选择值，使用现有 `llm:<providerId>:<modelId>` 编码格式保存到本地 `localStorage`。

默认解析顺序：

1. 已保存的全局资产生图模型。
2. 大模型设置里的当前默认图片模型。
3. 图片模型列表中的第一个可用模型。
4. 没有可用图片模型时显示“未选择模型”，生成按钮仍会由后端按大模型默认配置处理或返回明确错误。

### 资产详情

单个资产详情不再显示可编辑模型下拉。原位置改成只读信息块：

- 标题：`全局生图模型`
- 内容：当前全局模型标签，例如 `佳速 API / GPT Image 2`
- 操作：提供“设置”按钮打开资产生图设置弹窗。

单个资产保存信息时不再把 `image_model` 作为当前表单选择来源；历史字段不主动修改。

### 生图调用

单个资产 AI 生图从 `settings.imageModelValue` 解析 `provider_id` 和 `model_id`，传给 `generateAssetImageWithLlm`。

批量生图同样解析全局模型，并把 `provider_id` 和 `model_id` 传给批量接口。后端已有 LLM 资产生图接口支持按请求覆盖 provider/model；如果请求未带模型，仍按大模型默认配置兜底。

### 新建资产

新建资产弹窗不再出现“生图模型”。新建资产仍保存名称、别名、描述、画幅和上传文件。创建接口里的 `image_model` 字段继续传默认兼容值，避免影响旧后端字段约束。

## 错误处理

- 如果全局模型指向已删除或已禁用的模型，前端显示“未选择可用模型”，并建议打开“生图设置”重新选择。
- 如果用户直接点击生图且后端无法解析默认模型，沿用现有错误提示展示。
- 保存生图设置时不校验提示词以外的非关键项，避免用户暂时没有模型时无法保存提示词。

## 测试

- 前端构建必须通过。
- 增加或使用本地临时测试覆盖：
  - 全局模型值能解析成 `provider_id/model_id`。
  - 单资产生图请求使用全局模型，而不是资产自身 `image_model`。
  - 批量生图请求使用全局模型。
  - 单资产详情和新建资产弹窗不再渲染模型下拉。
