# 分镜工作台 C 版布局与提交参数设计

## 目标

把即梦批量工作台从表格型操作台调整为更适合长提示词和资产预览的卡片式工作台，同时把视频生成参数移动到提交动作附近，避免设置页里的默认参数和实际提交行为产生混淆。

## 范围

- 顶部应用框架固定在视口顶端，整体更紧凑；剧本列表、分镜工作台、资产管理、即梦排队、生成记录、即梦设置都在固定顶部下方滚动。
- 分镜工作台左侧分镜列表和右侧详情面板独立滚动；左侧滚动不影响右侧预览和提交按钮位置。
- 分镜列表改成卡片式行，不再出现横向滚动；选中的分镜要更亮，聚焦但未勾选时右侧仍可单独提交当前分镜。
- 分镜提示词固定高度，内部滚动；点击“编辑”或双击提示词区域进入编辑，编辑框固定高度。
- 增加全选分镜；批量提交旁边提供提交参数弹窗。
- 单独提交的生成参数放在右侧详情面板提交按钮上方。
- 已绑定且有音色的角色显示亮色小喇叭，可手动开关；关闭后仅影响本次页面显示和后续提交资产引用选择。
- 即梦设置页登录后隐藏登录/重新登录/调试登录等不必要按钮，只保留查询积分、退出登录、检测 CLI 等必要动作。
- 文档补充缓存位置、全局模板用途、截图说明和 EXE 打包说明。

## 数据与后端

队列项继续使用现有 `asset_snapshot` JSON。新增 `asset_snapshot.generation_settings` 保存本次提交的视频生成参数：

```json
{
  "generation_settings": {
    "model_version": "seedance2.0fast",
    "duration": 5,
    "ratio": "9:16",
    "video_resolution": "720p"
  }
}
```

`poll_seconds` 使用 `queue_items.poll_seconds` 字段保存。队列 worker 处理任务时优先读取队列项参数，缺失时才回退到 worker 默认值。

## 交互

- 点击分镜卡片：右侧显示该分镜的视频候选和“提交当前分镜”。
- 勾选分镜：进入批量操作范围；右侧仍以当前聚焦分镜为主。
- 全选：选择当前项目所有分镜，再用批量提交弹窗确认参数。
- 批量提交：按钮旁的设置按钮打开参数弹窗，确认后批量入队。
- 单独提交：右侧详情面板参数区直接修改本次提交参数，再点提交当前分镜。

## 验证

- 后端测试覆盖队列 worker 使用队列项生成参数。
- 前端构建通过。
- 浏览器检查浅色/深色主题、顶部固定、左右独立滚动、单个提交、全选和批量设置入口。
