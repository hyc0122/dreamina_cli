# 即梦cli自动排队助手打包版使用说明

当前稳定版以官方单账号 Dreamina CLI 为生成通道。打包目录必须整体复制，不能只复制 EXE。

## 1. 启动与关闭

双击 EXE 后，原生启动管理器会立即显示“启动程序中”，随后启动本地 API、独立队列 worker 和界面服务。启动器可打开软件、扫描端口、查看使用说明、提交问题反馈和关闭服务，并显示当前版本与微信客服 `jmqh888`。

- 只关闭浏览器：本地服务和 worker 仍可能继续运行。
- 在启动器点击“关闭服务”：关闭当前目录启动的所有服务。
- 队列页显示 worker 在线状态、最近心跳和在途任务数，可用于判断队列是否还在工作。

## 2. 数据位置

打包版数据默认保存在 EXE 同级 `data` 目录：

```text
data\jimeng.sqlite3
data\output\jimeng\projects\<project_id>\assets
data\output\jimeng\projects\<project_id>\videos
data\logs\desktop.log
```

- `jimeng.sqlite3`：项目、分镜、资产、绑定、队列、候选视频和全局设置。
- `assets`：角色、场景、道具图片和角色音色。
- `videos`：生成视频、下载结果和手动上传候选。
- `desktop.log`：启动、端口和服务错误日志。

升级时保留 `data` 目录。官方 CLI 登录凭证由即梦 CLI 自己保存在当前 Windows 用户目录的 `.dreamina_cli` 中，不属于项目数据库。

## 3. 即梦登录

进入“即梦设置”：

1. 检测 CLI；未安装时可使用一键安装。
2. 点击登录授权，浏览器会打开即梦 OAuth 页面。
3. 确认授权后，软件自动检测登录并查询积分。
4. 也可打开官方登录 JSON 页面，手动复制 JSON 后点击“导入浏览器 JSON”。

稳定版不提供实验性多账号或第三方 sessionid 通道。

## 4. 队列规则

API 和队列 worker 是独立进程。默认提交间隔 3 秒，最大在途任务 10 条，结果轮询间隔 30 秒，均可在“即梦设置 -> 队列调度”修改。

任务提交成功后，worker 会继续提交下一条，同时轮询未回传任务。队列满、限流和暂时网络错误会退避重试；登录失效和积分不足会阻塞；参数错误直接失败。

## 5. 视频导出

- 单个候选：分镜右侧点击“下载当前视频”，选择文件夹后保存为 `分镜N.mp4`。
- 批量默认视频：勾选分镜后点击批量下载，选择文件夹；软件新建“剧本名+年月日时分”目录并保存 `分镜1.mp4`、`分镜2.mp4`。

## 6. 多开规则

同一发布目录只运行一套服务并复用端口，避免两个进程同时写同一个 SQLite。不同发布目录拥有各自的 `data`，相互独立。

健康检查示例：

```text
http://127.0.0.1:<当前端口>/health
```
