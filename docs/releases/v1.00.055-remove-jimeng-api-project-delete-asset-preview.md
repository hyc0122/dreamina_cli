# v1.00.055 删除即梦 API 通道与界面修复

- 更新时间：2026-06-26 12:00:00 +08:00
- 更新类型：功能回退 / 界面修复

## 修改内容

删除不可用的即梦 API 通道，恢复官方 CLI 作为唯一视频提交通道。

本次移除了前端“即梦 API”导航页、api-* 视频模型选项、jimeng_api provider 映射，以及后端 jimeng_api provider 工厂和运行设置字段。历史队列或历史设置中如果残留 api-* 模型，前端参数设置会自动回退到官方 CLI 默认模型。

## 剧本删除

剧本列表中的每个剧本卡片新增“删除”按钮。点击后会弹出确认提示，说明会删除该剧本及其分镜、资产、候选视频等项目数据。删除当前打开的剧本后，前端会清空当前项目状态并回到剧本列表。

## 资产显示

资产管理列表卡片和右侧详情主图改为完整展示图片，不再使用裁切填充，避免角色设定图或拼图左侧内容显示不完整。
