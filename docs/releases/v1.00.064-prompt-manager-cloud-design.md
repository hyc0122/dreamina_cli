## 更新内容

本次更新确认“提示词管理”模块和独立云端提示词同步项目的设计方案，还未进入功能实现。

## 主要设计

- 左侧新增独立大模块“提示词管理”，只共用全局主题，不串联漫剧项目、分镜工作台、资产管理、即梦队列和创作助手。
- 提示词模板分为“视频创作提示词”和“创作作品提示词”两大组。
- 视频创作提示词包含提示词推理、故事情节、角色提取、场景提取、物品提取、分镜调整。
- 创作作品提示词包含小说转分镜提示词。
- 模板编辑器支持内容分隔符、记录分隔符、输出开始符、输出结束符的预设下拉和自定义输入。
- 增加大模型 SOP 提示词输入区，并自动组合生成完整提示词，支持一键复制。
- 本地提示词管理使用独立 `prompt_manager.sqlite3`，不写入现有 `jimeng.sqlite3`。
- 云端同步项目使用独立数据库，例如 `prompt_cloud.sqlite3`，不能和主软件数据库混用。
- 云端提示词分为免费版本、用户上传板块和 VIP 版本提示词。
- VIP 提示词第一阶段只做后台管理预留，不同步到本地。

## 同步规则

- 本地手动同步只拉取云端免费模板。
- 本地新建用户模板会静默自动上传到云端用户上传板块。
- 上传失败不打断用户，进入待同步队列，后续启动或手动同步时重试。
- 重复模板名自动追加序号，例如 `模板名 (2)`。
