# v1.00.028 分镜音色试听与提交前校验

- 更新时间：2026-06-21 13:56:00 +08:00
- 更新类型：交互优化 / Bug 修复 / 队列管理

## 更新概述

本次集中处理分镜工作台的角色音色使用体验和提交前校验。角色资产卡片现在可以直接试听音色；全能参考音频数量在提交前就会校验，避免分镜先进入队列、前端显示“视频制作中”，再由 worker 返回失败。

## 功能更新

- 分镜工作台已绑定的角色卡片新增“试听音色”按钮。
- 右侧“选择角色”抽屉中的角色列表也支持直接试听音色，不需要先进入资产管理。
- 已绑定角色仍保留原来的“启用 / 关闭音色”按钮，用于控制该角色音色是否参与本次全能参考。
- 即梦排队页中，已取消的队列记录新增删除按钮；删除只移除这条排队记录，不会删除分镜、资产或已生成视频文件。

## Bug 修复

- 提交当前分镜或批量提交前，会统计目标分镜中已启用且有音色文件的角色资产。
- 当全能参考音频超过 3 段时，前端直接阻止提交，并提示“请关闭多余角色音色”。
- 修复 worker 返回失败后，分镜存在 `last_error` 但右侧提交按钮仍显示“视频制作中”的兜底显示问题。
- 分镜列表中只要存在失败错误信息，状态标签优先显示“失败”，避免 queued/running 状态滞留造成误解。

## 技术说明

- 前端新增 `submitReferenceIssueForShot`，在 `requestSubmitShots` 阶段完成全能参考音频数量校验。
- `AssetMiniCard` 统一提供音色试听入口，分镜绑定区和资产选择抽屉复用同一套卡片交互。
- 资产选择抽屉移除卡片外层按钮嵌套，避免点击试听时误触发绑定资产。
- 后端新增删除已取消队列记录的存储方法和 API：`DELETE /jimeng/queue/items/{queue_item_id}`。

## 影响范围

- 影响页面：分镜工作台、右侧资产选择抽屉、即梦排队页。
- 影响提交模式：`自动判断` 和 `全能参考` 会进行音频数量预校验；`纯文本生成` 不做音频参考校验。
- 不改变即梦 CLI 的最终音频限制，仍以最多 3 段全能参考音频为准。
