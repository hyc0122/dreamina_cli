# v1.00.058 创作助手导航与全局主题适配

更新时间：2026-06-26 14:37:50 +08:00

## 更新概览

本次更新围绕创作助手接入后的导航层级和视觉一致性进行修正。创作助手现在作为独立模块显示在漫剧制作上方，原创作助手内部的小说创作、剧本创作、15 秒分镜稿创作、作品评测等入口作为页面内二级菜单保留，不再覆盖主应用的一级菜单。

## 具体修改

- 主应用左侧导航拆分为“创作助手”和“漫剧制作”两个分组。
- “漫剧制作”分组保留剧本列表、分镜工作台、资产管理。
- 创作助手内部侧栏从浏览器固定定位改为页面内部二级侧栏，避免遮挡主应用菜单。
- 移除创作助手模块对全局 body 背景色的覆盖，避免污染其他页面主题。
- 创作助手整体背景、面板、边框和文字颜色改为跟随当前全局深色/浅色主题。
- 保留原创作助手的彩色进度条、渐变主按钮、蓝色步骤高亮和关键状态色。
- 主应用菜单、移动端菜单和创作助手内部可点击菜单增加彩色 hover 反馈。
