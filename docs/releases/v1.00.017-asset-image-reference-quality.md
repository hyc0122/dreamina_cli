# v1.00.017 资产生图参考图与质量参数

- 更新时间：2026-06-21 00:22:35 +08:00
- 更新名称：资产 AI 生图参考图地址、图片质量和批量生图弹窗

## 更新内容

1. 单个资产 AI 生图新增“参考图地址”输入框，多个图片 URL 可用换行、逗号、顿号或空格分隔。
2. 单个资产 AI 生图新增图片质量选择，默认 `high`，会发送到大模型接口 `params.quality`。
3. 批量生图从直接确认提交改为弹窗形式，弹窗内集中确认全局生图模型、分辨率、图片质量和参考图地址。
4. 批量生图支持和单个生图一致的参考图地址，填写后会随每个资产生图请求传入。
5. 后端大模型资产生图请求新增 `quality` 和 `reference_images` 字段。
6. 佳速 API 请求体保持 `model`、`prompt`、`params` 结构；`params` 固定包含 `size` 和 `quality`，仅当填写参考图地址时才额外包含 `images`。
7. 生图记录会保存本次质量和参考图地址，方便后续回查。

## 修复问题

1. 补齐资产图生图参考图能力，避免只能纯文本生成资产图。
2. 批量生图提交前可以明确检查参数，减少误点后直接批量提交的问题。
3. 图片质量不再固定为后端默认值，界面和请求参数保持一致。

## 使用说明

1. 单个资产：在资产详情右侧填写“参考图地址”，选择“质量”，再点击 `AI 生图`。
2. 批量资产：勾选资产后点击 `批量生图`，在弹窗中选择分辨率、图片质量并填写可选参考图地址。
3. 不填写参考图地址时，请求不会携带 `images` 参数。
4. 参考图地址最多取前 10 个 URL。
