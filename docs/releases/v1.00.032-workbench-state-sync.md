# v1.00.032 分镜工作台状态同步修复

更新时间：2026-06-21 18:27:38 +08:00

## 更新名称

分镜工作台状态同步修复

## 修改内容

- 修复分镜提示词高亮丢失的问题：前端在项目加载、资产刷新和单条提示词保存后，会根据当前资产列表本地计算高亮，不再依赖重新匹配后端才显示颜色。
- 高亮计算按小批量空闲调度执行，避免在大项目里一次性计算所有分镜造成编辑、保存、取消时卡顿。
- 修复重新点击“匹配选中资产”后右侧资产临时消失的问题：匹配接口返回的是本次新增绑定，前端现在会在匹配完成后重新读取选中分镜的完整绑定列表。
- 修复右侧已有候选视频但左侧视频图标未点亮的问题：项目加载时批量读取候选视频状态，分镜列表用候选视频表兜底判断是否已有视频。
- 左侧视频图标现在能区分已有锁定视频、已有默认视频和已有候选视频，避免分镜表字段与候选视频表不同步造成误判。

## 影响范围

- 分镜工作台提示词展示和编辑。
- 分镜资产匹配后的绑定展示。
- 分镜列表视频状态图标。
