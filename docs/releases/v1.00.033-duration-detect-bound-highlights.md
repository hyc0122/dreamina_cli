# v1.00.033 推荐时长识别与提示词高亮边界修复

更新时间：2026-06-21 19:26:47 +08:00

## 更新名称

推荐时长识别与提示词高亮边界修复

## 修改内容

- 批量检测时长支持识别 `推荐时长：约12秒`、`建议时长：大约9秒` 这类写法。
- 保留原有 `总时长`、`镜头时长`、`时长` 和 `duration: 9s` 的识别方式。
- 分镜提示词高亮不再使用全项目资产自动计算，避免还没点击“匹配选中资产”时提示词提前变色。
- 高亮现在只根据当前分镜已绑定资产计算：未绑定资产时不显示颜色，匹配或手动绑定后再显示对应颜色。
- 保存提示词、刷新资产、刷新分镜绑定后都会按当前绑定资产重新计算高亮。

## 影响范围

- 分镜工作台批量检测时长。
- 分镜提示词资产高亮显示。
- 分镜匹配资产和手动绑定资产后的高亮刷新。
