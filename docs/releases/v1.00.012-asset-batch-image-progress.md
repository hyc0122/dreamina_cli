# v1.00.012 资产批量生图进度提示优化

更新时间：2026-06-20 23:00:18 +08:00

## 更新名称

资产批量生图进度提示优化

## 问题背景

资产管理批量生图原来会显示全屏等待遮罩，并在按钮中使用动态图标。批量任务时间较长时，遮罩会阻挡资产管理页面操作，也不方便观察当前处理进度。

## 修改内容

- 移除资产管理批量生图时的全屏等待遮罩。
- 移除“批量生图”按钮里的旋转等待动态图标。
- 在资产管理页面顶部新增红色进度提示文字。
- 批量任务开始时提示准备生成的资产数量。
- 每个批量分组提交前提示当前处理范围和画幅。
- 每个批量分组完成后提示已处理数量、成功数量和失败数量。
- 批量生图按钮在任务执行期间仍会禁用，避免重复提交。

## 使用说明

1. 在资产管理中勾选需要生图的资产。
2. 点击“批量生图”。
3. 页面顶部会显示红色进度提示，不再弹出遮罩等待层。
4. 任务完成后显示成功和失败数量，并自动刷新资产库。

## 注意事项

- 后端批量接口按分组返回结果，前端进度以分组为单位更新。
- 这次只调整资产管理页面的批量生图体验，不影响单个资产 AI 生图。
