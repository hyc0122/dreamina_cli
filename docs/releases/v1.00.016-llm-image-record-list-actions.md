# v1.00.016 大模型生图记录交互优化

- 更新时间：2026-06-20 23:59:14 +08:00
- 更新名称：大模型生图记录排序、单列展示和批量删除

## 更新内容

1. 资产管理页会读取当前项目的大模型生图记录。
2. 单个资产只要存在未完成、超时或获取异常的生图记录，并且没有手动取消，右侧 `AI 生图` 按钮会保持 `生图中` 状态，避免重复提交。
3. 大模型生图记录改为按提交时间 `created_at` 倒序排列，不再因为继续获取导致排序跳动。
4. 大模型生图记录页改为单列行式展示，每条记录占一行，便于横向查看 task_id、状态、模型、提交时间、进度和反馈。
5. 大模型生图记录支持勾选、全选当前筛选结果和批量删除。
6. 后端新增批量删除记录接口，一次删除多条记录；删除记录不删除已经保存到资产里的图片。

## 修复问题

1. 修复远端图片尚未获取、记录也未取消时，资产详情里的 `AI 生图` 按钮又恢复可点击的问题。
2. 修复记录按更新时间排序导致继续获取后位置变化的问题。
3. 优化记录页多列卡片过于分散的问题。

## 使用说明

1. 在资产管理提交 AI 生图后，如果任务未完成，当前资产按钮会显示 `生图中`。
2. 进入“生成记录 -> 大模型生图记录”，记录会按提交时间从新到旧排列。
3. 勾选多条记录后点击“批量删除记录”，只会删除本地记录，不影响已保存的资产图片。
