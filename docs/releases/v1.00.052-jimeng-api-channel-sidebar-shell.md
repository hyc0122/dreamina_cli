# v1.00.052 - jimeng-api 正式通道和左侧工作台布局

更新时间：2026-06-25 22:19:08 +08:00

## 更新名称

jimeng-api 正式通道和左侧工作台布局

## 修改内容

- 删除“网页测试”和“JiMengHub”临时入口，包括前端页面、导航入口、后端 API 路由、旧 provider、旧网页 session client 与旧存储封装。
- 新增“即梦 API”设置页，用于配置 `jimeng-api` 服务地址、SessionID 账号池、默认 `api-*` 视频模型、画幅、时长、分辨率和并发账号数。
- 分镜生成设置新增 `api-*` 模型组，选择这类模型时会自动映射到后端 `jimeng_api` provider。
- 后端队列和 worker 增加 `jimeng_api` provider 工厂，按运行设置读取 `jimeng_api_base_url` 和 `jimeng_api_sessions`。
- 后端运行设置白名单加入 `jimeng_api_*` 配置，避免保存后被清理或重启后丢失。
- 主应用外壳改为左侧分组导航布局，分为“创作 / 生产 / 配置”，并保留顶部版本号、根目录、使用说明、问题反馈、积分和主题切换。
- “即梦设置”入口改名为“官方CLI”，用于和新增的“即梦 API”通道区分。

## 验证

- 已执行 `npm run build`，前端 TypeScript 和 Vite 构建通过。
- 已执行 `python -m compileall backend/app`，后端模块编译通过。
- 已扫描正式源码，`网页测试`、`JiMengHub`、`jimeng_hub`、`web_session`、`hub-*` 等旧入口关键词已不再出现在 `frontend/src` 和 `backend/app` 中。
