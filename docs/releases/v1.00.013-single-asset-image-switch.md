# v1.00.013 单个资产 AI 生图切换修复

更新时间：2026-06-20 23:02:52 +08:00

## 更新名称

单个资产 AI 生图切换修复

## 问题背景

资产管理中单个资产执行 AI 生图后，如果马上切换到下一个资产，详情面板里的生图提交状态可能仍沿用上一个资产，导致下一个资产的“AI 生图”按钮无法继续提交。

## 修改内容

- 单张资产 AI 生图状态从全局布尔值改为按资产 ID 记录。
- 当前资产是否处于“生图中”，只根据当前资产 ID 判断。
- A 资产提交中时，切换到 B 资产后，B 资产可以继续提交 AI 生图。
- 旧资产请求完成后，不会把成功或失败提示写到当前新资产面板上。
- 旧资产请求完成后仍会刷新资产库，保证生成结果可以回到列表中查看。

## 影响范围

- 影响资产管理右侧单个资产详情面板。
- 只调整单个资产 AI 生图提交状态。
- 不影响批量生图、上传图片、上传音色和资产信息保存。
