# v1.00.050 JiMengHub 多账号网页通道

- 更新时间：2026-06-25 21:08:40 +08:00
- 更新类型：新增功能、队列通道、前端入口、版本同步

## 更新概要

本次新增 `JiMengHub` 正式多账号网页通道，并保留原官方 CLI 通道不变。用户可以在独立 JiMengHub 页面维护网页 Cookie 账号池，在分镜提交参数里选择 `hub-*` 模型后，队列会自动使用 `jimeng_hub` provider，而不是继续走官方 CLI。

## 主要修改

- 新增后端 `JimengHubProvider`，把主队列的 `VideoGenerationProvider` 协议适配到现有网页 Cookie 请求链路。
- 新增 `/jimeng/hub/*` API alias，用于正式 JiMengHub 账号池、测试任务提交和轮询。
- 队列 worker 不再强制所有任务走 `dreamina_cli`，会按队列快照中的 provider 选择官方 CLI 或 JiMengHub。
- 前端新增 `JiMengHub` 页面，支持添加 Cookie 账号、粘贴 Cookie、打开即梦网页、查看 Cookie 教程、提交测试和轮询结果。
- 分镜视频模型选择新增 `JiMengHub` 分组，显示 `hub-seedance2.0` 系列模型；后端会映射为即梦网页接口实际模型名。
- 原“即梦设置”导航改名为“官方CLI”，减少和 JiMengHub 多账号通道的混淆。

## 使用说明

1. 在 `JiMengHub` 页面添加账号，建议粘贴即梦网页 Network 请求里的完整 Cookie。
2. 在分镜工作台的提交参数里选择 `JiMengHub` 分组下的 `hub-*` 模型。
3. 单个或批量提交分镜后，队列会以 `jimeng_hub` provider 入队。
4. 同一个任务提交、后续轮询和下载都使用提交时绑定的同一个账号 Cookie。

## 注意事项

- 只填 sessionid 时，系统会尝试补齐本地指纹 Cookie，但稳定性不如完整 Cookie。
- 浏览器安全策略不允许本工具一键读取即梦站点 Cookie，因此仍需要用户手动复制完整 Cookie。
- JiMengHub 通道处于内测阶段，建议先小批量测试。
- 需要同步云端版本号页面 `https://version.j11.net/` 到 `v1.00.050`，否则旧版强制更新检测会继续提示升级。
