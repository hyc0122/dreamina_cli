# v1.00.048 即梦排队列表查询和排序优化

- 更新时间：2026-06-25 00:35:30 +08:00
- 更新类型：功能优化 / 使用体验优化

## 更新概述

即梦排队列表改为更适合日常排查的查看方式：默认只查看今天的队列记录，默认按入队时间倒序显示，也就是最后提交的任务显示在最上面。

## 具体修改

- 即梦排队列表新增“查看时间”筛选。
- 默认筛选范围为“今天”。
- 支持快速切换“今天 / 一周 / 一月”。
- 支持手动选择开始日期和结束日期查看自定义区间。
- 默认排序为“最新在上”。
- 支持手动切换“最新在上 / 最早在上”。
- 队列表格新增“时间”列，显示入队时间和下发时间。
- 后端队列查询接口新增 `created_from`、`created_to`、`sort_order` 参数，避免前端一次性拉取全部历史记录。
- 队列显示排序不会改变真实排队执行顺序；上移、下移和 worker 提交仍按原队列位置执行。

## 使用说明

进入“即梦排队”页面后，系统会自动显示今天的队列记录，并把最新提交的任务排在最上方。

需要查看历史任务时，可以切换到“一周”或“一月”；如果需要精确查看某几天，可以选择自定义日期区间。
