# v1.00.003 佳速图片生图接口终态轮询修复

更新时间：2026-06-20 13:54:54 +08:00

## 更新名称

佳速图片生图接口终态轮询修复

## 功能与 Bug

- 修复资产管理里大模型生图报“接口未返回图片数据”的问题。
- 佳速图片生成任务现在严格按官方文档使用 is_final === true 判断终态，不再因为 state=success 但结果还没落盘时提前读取空 result_url。
- 佳速 /v1/media/generate 请求体保持 model、prompt、params 三段结构。
- params 内只提交 size 和 quality，不再额外提交 n、response_format 等图片参数。

## 修改内容

- 更新 backend/app/llm/client.py 的佳速图片任务轮询逻辑。
- 更新佳速图片生成请求参数组装，确保只传官方要求的图片比例 size 和图片质量 quality。
- 保留非佳速 OpenAI 兼容图片接口的原有 response_format=b64_json 逻辑。

## 验证记录

- 已用本地脚本验证佳速请求体只包含 model、prompt、params，且 params 只包含 size 和 quality。
- 已用本地脚本验证当 state=success 但 is_final=false 时会继续轮询，直到 is_final=true 后再读取 result_url 下载图片。
- 已运行 python -m compileall .\backend\app，后端代码编译通过。
