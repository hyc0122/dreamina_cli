# v1.00.030 角色分类导入导出中文化

- 更新时间：2026-06-21 15:10:08 +08:00
- 更新类型：导入导出格式 / 文档同步

## 更新概述

本次把用户可见的角色分类导入导出值改为中文“单人/群演”。导出的 JSON、CSV 和导入示例都不再要求用户理解英文枚举。

## 修改内容

- 资产导出 CSV 中，`character_kind` 字段直接输出 `单人` 或 `群演`。
- 资产导出 JSON 中，`character_kind` 字段直接输出 `单人` 或 `群演`。
- JSON 导入示例改为 `"character_kind": "单人"`。
- CSV 导入示例中的角色分类值改为 `单人`、`群演`。
- 导入弹窗提示改为“填写单人或群演”。
- `docs/使用说明.md` 同步改为中文值说明。

## 兼容说明

- 内部数据库仍保存标准值，避免影响现有筛选、生图和分类逻辑。
- 后端导入仍兼容旧值，旧文件不会因为这次改动失效。
- 用户新导出的文件会优先显示中文值。
