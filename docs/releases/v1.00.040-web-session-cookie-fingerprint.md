# v1.00.040 网页 SessionID Cookie 指纹补齐

更新时间：2026-06-22 22:15:44 +08:00

## 更新名称

网页 SessionID 完整 Cookie 与本地指纹补齐

## 修改内容

- 网页生视频测试账号现在支持粘贴完整浏览器 Cookie，不再只接受单个 sessionid。
- 只填写 sessionid 时，后端会自动补齐一套本地网页指纹 Cookie，包括 `_tea_web_id`、`s_v_web_id`、`fpk1`、`uifid`、`uifid_temp` 和 `x-web-secsdk-uid`。
- 后端会把补齐后的 Cookie JSON 保存到本地 SQLite；接口返回给前端时只显示脱敏 sessionid、Cookie 数量和是否已补指纹，不暴露完整凭证。
- 网页测试提交和后续轮询都会使用同一个账号保存的 Cookie，`_tea_web_id` 会同步进入请求参数里的 `webId`，避免提交和轮询使用不同指纹。
- 测试页面账号输入框改为多行输入，提示可粘贴 sessionid 或完整 Cookie，并在账号卡片显示 Cookie 数量和指纹状态。

## 影响范围

- 只影响“网页测试”页面和 `/jimeng/web-session/*` 独立测试接口。
- 不进入官方即梦 CLI 队列，不影响分镜工作台正常 CLI 提交流程。
- 已保存的旧账号会在数据库迁移后保留；旧账号如果没有 `cookie_json`，再次更新 sessionid 或新建账号时会生成完整指纹 Cookie。

## 验证重点

- 新增账号后页面应显示 `Cookie: 7 个` 或更多，并显示“已补指纹”。
- 使用完整 Cookie 新增账号时，应保留用户提供的 `_tea_web_id` 等字段。
- 提交任务和手动轮询任务时，应始终使用任务绑定账号的 Cookie，不切换到其他账号。
