# v1.00.036 居中放大预览与批量提交时长来源

- 更新时间：2026-06-21 20:31:57 +08:00
- 更新名称：资产预览与批量提交时长来源优化

## 功能调整

1. 资产悬停放大预览改为挂载到浏览器根节点，并固定在浏览器视口正中间显示。
2. 分镜工作台批量提交弹窗新增“时长来源”选项。
3. “时长来源”默认使用“按单分镜”，批量提交时优先读取每个分镜自己的时长配置。
4. 用户可以切换为“统一时长”，让本次批量提交全部使用弹窗里选择的视频时长。

## Bug 修复

1. 修复资产选择抽屉内悬停图片时，放大预览被右侧面板父级布局限制、没有显示在浏览器中心的问题。
2. 修复批量提交弹窗无法明确表达“统一时长”和“按分镜时长”两种提交策略的问题。

## 实现说明

1. `AssetCenteredPreview` 使用 `createPortal` 渲染到 `document.body`，避免被抽屉、面板或滚动容器的定位上下文影响。
2. `JimengVideoGenerationSettings` 新增 `duration_source` 字段，取值为 `per_shot` 或 `global`。
3. 本地队列快照生成时，只有 `duration_source` 为 `global` 才使用弹窗统一时长；默认 `per_shot` 会用分镜 `default_duration` 覆盖本次提交时长。
4. 没有单独配置时长的分镜仍会回退使用弹窗里的时长，避免提交参数为空。
