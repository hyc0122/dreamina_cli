# v1.00.049 分镜工作台引导和匹配优化

更新时间：2026-06-25 13:38:43 +08:00

## 更新名称

分镜工作台引导和匹配优化

## 更新内容

- 分镜工作台新增“全选未制作视频”按钮，按钮显示未制作数量；工具栏下方会持续显示未制作视频清单，点击后会选中这些分镜并提示已选数量。
- 新增新手引导模块，覆盖新建剧本、配置即梦 CLI、大模型设置、资产描述、资产生图、分镜导入、资产匹配、时长检测、批量设置模型、单个和批量提交等完整流程。
- 新建剧本时可选择继承旧项目某个分镜的已绑定资产，只复制角色、场景、道具和音色图片资产，不复制候选视频。
- 分镜资产自动匹配改为结构化匹配：角色只从人物字段匹配，场景只从场景字段匹配，道具只从道具字段匹配；同一分镜最多自动匹配一个场景。
- 人物名称支持括号等价，例如 `沈云禾[年轻时期]` 可匹配 `沈云禾(年轻时期)`，但不会只按 `沈云禾` 误匹配带状态的人物。
- 场景匹配会去掉昼夜括号后匹配完整场景名，例如 `青岚湾码头（白天）` 只匹配 `青岚湾码头`，不再误匹配短词 `码头`。
- 批量检测分镜时长支持更多“推荐时长/约等”写法；没有识别到时长的分镜会在提示中列出。
- 分镜工作台新增“分析无对白音频”，当角色资产有音频且出现在超过 3 个分镜时，可自动关闭没有对白、台词、VO、OS 等语音线索分镜里的角色音频。
- 分镜右侧新增手动拉取已提交视频入口，断网或程序关闭后可重新按已提交的队列记录拉取结果。
- 批量提交前会检查已生成视频的分镜，发现已生成视频会弹窗提示并停止批量提交，避免误覆盖。
- 分镜提示词高亮支持未绑定资产灰色提示，已绑定资产保持分类亮色，方便看出“文本里提到了但还没匹配到”的资产。

## 影响范围

- 前端：分镜工作台、项目列表、新手引导、提示词高亮、队列手动拉取入口。
- 后端：分镜资产匹配、批量时长检测、无对白音频分析、队列单项手动轮询、创建项目继承资产。
- 文档：README 当前版本、CHANGELOG 和本详细发布说明。
