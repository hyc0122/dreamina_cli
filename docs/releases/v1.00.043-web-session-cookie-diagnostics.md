# v1.00.043 网页 Session Cookie 诊断

更新时间：2026-06-23 01:07:19 +08:00

## 更新名称

网页 Session Cookie 诊断与 4013 风控提示。

## 修改内容

- 网页 Session 测试账号新增 Cookie 完整度判断，账号池会显示当前账号是否缺少真实浏览器 Cookie。
- 对仅填写 sessionid 后由本地补齐指纹的账号，不再只显示“已补指纹”，而是提示缺少 `ttwid`、`odin_tt`、`user_spaces_idc` 等浏览器 Cookie。
- 即梦网页接口返回 `ret=4013` 时，任务错误信息会追加诊断说明，提示从已登录即梦网页的 Network 请求中复制完整 Cookie 后重新保存账号。
- 保留原有 `jimeng-web2api-master` 风格的 `aigc_draft/generate` 提交和 `get_history_by_ids` 轮询链路，不把网页测试任务混入官方 CLI 队列。

## 使用说明

- 如果页面显示 `Cookie: 7 个 · 缺少浏览器 Cookie`，说明账号只具备 sessionid 和本地补齐指纹，容易触发 4013。
- 建议在浏览器登录即梦后，打开开发者工具 Network，任选一个 `jimeng.jianying.com` 的已登录请求，复制完整 `Cookie` 请求头，重新添加或更新网页测试账号。
- 粘贴完整 Cookie 后，账号池应显示 `完整 Cookie`；如果仍然 4013，通常需要重新复制最新 Cookie、降低提交频率或更换账号测试。
