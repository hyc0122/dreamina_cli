# v1.00.002 资产画风分类与佳速媒体生图接口适配

更新时间：2026-06-20 13:30:12 +08:00

## 更新概要

本次更新修复佳速 API 大模型生图接口路径不匹配导致的 HTTP 404，并把资产生图提示词从旧的单一提示词结构调整为画风风格结构，支持角色单人/群演和场景分别配置画风。

## 详细内容

- 佳速 API 资产纯文本生图改用 `POST /v1/media/generate`，不再请求 `/v1/images/generations`。
- 大模型生图返回解析兼容 base64、图片 URL、media URL、file URL 等常见结构。
- 最终资产生图提示词会清理 `【...】` 标题行，避免发送多余标签。
- 资产生图设置新增全局画风、单人人物画风、群演人物画风、场景画风。
- 风格库支持选择附加目标，可把风格追加到全局、单人、群演或场景画风。
- 角色资产新增单人/群演分类，资产详情、新建资产、资产列表和工作台资产卡片都会显示或保留该分类。
- 角色批量资产生图会按单人/群演拆分调用 LLM 批量接口，分别使用对应画风。
- JSON/CSV 资产描述导入导出支持 `character_kind`，项目复制和队列资产快照会保留角色分类。
- 大模型设置页底部的兜底项改为默认画风提示词说明，避免和资产管理生图设置混淆。

## 兼容说明

- 旧本地设置里的 `imagePromptTemplate` 会迁移到新的 `globalStylePrompt`，保存后不再写回旧字段。
- `character_kind` 对角色资产有效，取值为 `single` 或 `group`；旧角色资产默认按 `single` 处理。
- 大模型设置中的 `asset_image.global_prompt` 继续作为后端兜底字段保留；资产管理传入画风时优先使用资产管理设置。
