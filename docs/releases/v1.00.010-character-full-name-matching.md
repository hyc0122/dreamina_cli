# v1.00.010 人物角色完整匹配修复

更新时间：2026-06-20 20:59:23 +08:00

## 更新名称

人物角色完整匹配修复

## 问题背景

人物资产匹配原来会按字符串片段查找，存在基础姓名误匹配阶段角色的风险。例如资产里同时存在 `沈云禾` 和 `沈云禾[年轻时期]` 时，分镜人物写成 `沈云禾[年轻时期]`，基础角色 `沈云禾` 不应该被自动绑定。

## 修改内容

- 人物角色匹配优先读取分镜文本中的 `人物：` 行。
- `人物：` 行按 `、`、逗号、分号等分隔符拆分为独立人物名称。
- 人物资产必须和拆分后的完整人物名称匹配，不能只匹配名称的一部分。
- 中英文括号和全角括号视为等价：
  - `沈云禾[年轻时期]`
  - `沈云禾(年轻时期)`
  - `沈云禾（年轻时期）`
- 当分镜没有 `人物：` 行时，保留兼容兜底匹配，但会阻止 `沈云禾` 直接匹配 `沈云禾[年轻时期]` 这类阶段角色。

## 示例

- `沈云禾[年轻时期]` 可以匹配 `沈云禾(年轻时期)`。
- `沈云禾[年轻时期]` 可以匹配 `沈云禾（年轻时期）`。
- `沈云禾` 不能只按姓名匹配 `沈云禾[年轻时期]`。

## 影响范围

- 影响分镜工作台的“匹配资产”功能。
- 影响人物角色的自动绑定和高亮。
- 场景、道具匹配逻辑保持原有行为。
