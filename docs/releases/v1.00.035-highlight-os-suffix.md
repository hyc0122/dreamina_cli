# v1.00.035 人物状态名后缀高亮修复

更新时间：2026-06-21 20:03:50 +08:00

## 更新名称

人物状态名后缀高亮修复

## 修改内容

- 修复 `沈云禾[朴素状态]（OS）：` 这类提示词不高亮的问题。
- 带状态人物名后面紧跟 `（OS）`、`（VO）`、`（旁白）`、`（内心）` 等语音标记时，会正常高亮人物名本体。
- 保留裸名防误匹配规则：资产只有 `沈云禾` 时，不会误高亮 `沈云禾[朴素状态]`。
- 兼容中英文括号和 `O.S.`、`V.O.` 等写法。

## 影响范围

- 分镜工作台提示词全文高亮。
- 角色名后接旁白、内心、OS、VO 标记的对白/画外音提示词。

## 验证

- `npm test`
- `npm run build`
