# v1.00.038 SessionID 网页生视频测试通道

更新时间：2026-06-22 14:23:17 +08:00

## 更新名称

SessionID 网页生视频测试通道

## 更新内容

- 新增独立“网页测试”页面，用于验证 `sessionid` 拼 Cookie 直连即梦网页接口的生视频流程。
- 新增网页 SessionID 账号池，账号完整 `sessionid` 只保存在本地 SQLite，前端只显示脱敏值。
- 新增独立网页测试任务表，每个任务在提交时绑定账号，后续轮询结果继续使用同一个账号，不会混用其他账号。
- 新增后端 `/jimeng/web-session/*` 接口，独立于官方 CLI 队列和分镜生产队列。
- 新增即梦网页请求辅助逻辑：构造 `sessionid/sessionid_ss/sid_tt/sid_guard` Cookie，请求 `/mweb/v1/aigc_draft/generate`，并通过 `/mweb/v1/get_history_by_ids` 手动轮询结果。
- 新增最小测试覆盖账号脱敏、Cookie 拼接、任务账号绑定和同账号轮询，避免后续改动破坏多账号请求边界。

## 使用说明

1. 打开顶部导航“网页测试”。
2. 添加账号名称和对应 `sessionid`。
3. 选择账号、模型、画幅、时长和分辨率。
4. 输入提示词后点击“提交网页测试”。
5. 在右侧任务记录中点击“轮询”，查看是否拿到远端结果地址。

## 注意事项

- 这是独立测试入口，不进入“即梦排队”，也不会影响分镜工作台已有的官方 CLI 提交流程。
- 当前只用于验证 sessionid-cookie 网页请求和多账号绑定链路，后续确认稳定后再考虑接入正式分镜队列。
- `sessionid` 属于敏感凭据，不要提交到 GitHub，也不要写入 README 或公开文档。
