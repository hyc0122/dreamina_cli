# v1.00.005 资产批量生图改为按勾选资产执行

更新时间：2026-06-20 14:36:30 +08:00

## 更新名称

资产批量生图改为按勾选资产执行

## 功能与 Bug

- 修复资产管理“批量生图”会按当前筛选结果全部生成的问题。
- 批量生图现在只处理当前资产类型中已勾选的资产。
- 没有勾选资产时，会提示先勾选要批量生图的资产。
- 勾选资产里没有填写详情描述 / 生图提示词时，会提示补充详情描述，不会提交空任务。
- 确认弹窗文案改为“选中的 X 个资产”，避免误解为当前全部角色或全部场景。

## 修改内容

- 更新 frontend/src/components/jimeng/pages/JimengAssetManagerPage.tsx。
- 新增 selectedCurrentTypeAssets 计算，只从 selectedAssetIds 中取当前 tab 类型资产。
- batchGenerateImages 改为使用 selectedCurrentTypeAssets，而不是 filteredAssets。

## 验证记录

- 已运行 npm run build，前端 TypeScript 与 Vite 构建通过。
- 已静态检查批量生图文案，确认不再使用“当前筛选出的”作为提交范围。
