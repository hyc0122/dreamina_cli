# v1.00.046 分镜工作台队列状态兜底修复

- 更新时间：2026-06-24 13:53:31 +08:00
- 更新名称：分镜工作台队列状态兜底修复

## 修复内容

- 修复“后台队列已经取消，但分镜工作台右侧仍显示视频制作中、不能再次提交”的问题。
- 右侧提交按钮不再只依赖分镜表里的 `queued/running` 状态，而是结合当前队列事实判断。
- 只要该分镜没有等待、阻塞、重试等待、提交中、运行中或轮询中的队列项，就不会继续锁住提交按钮。
- 已取消、已失败、已完成的队列项不会再让分镜显示为制作中。
- 左侧分镜状态标签同步使用同一套判断：旧状态还写着 queued/running，但队列已经结束时，会按是否已有候选视频显示为已完成或草稿。

## 影响范围

- 分镜工作台右侧视频预览提交按钮。
- 分镜工作台左侧分镜状态标签。
- 即梦排队页面数据不变，只用于给工作台判断当前分镜是否仍有活跃队列。

- `npm run test`
