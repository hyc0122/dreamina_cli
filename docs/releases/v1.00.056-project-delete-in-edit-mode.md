# v1.00.056 项目编辑删除入口调整

- 更新时间：2026-06-26 12:33:47 +08:00
- 更新名称：项目编辑删除入口调整

## 修改内容

- 将剧本删除按钮移动到剧本卡片的编辑状态按钮区。
- 普通剧本卡片操作区不再直接显示删除按钮，只保留编辑和进入工作台入口。
- 删除按钮仍使用原来的二次确认逻辑，删除当前剧本时会清空当前项目状态。
- 新增结构测试，约束删除按钮只在项目编辑状态显示，避免后续误改回普通卡片入口。
