# v1.00.068 分镜资产匹配分批与场景时间词修复

更新时间：2026-07-05 23:43:06 +08:00

## 更新名称

分镜资产匹配分批与场景时间词修复

## 修改原因

用户一次性全选大量分镜执行资产匹配时，旧逻辑会在一次请求里连续处理所有分镜，容易造成页面等待时间长、体感卡顿或服务压力过大。

同时，场景字段里如果把时间或光线放在前面，例如 `场景：日，酒店`，旧逻辑会把 `日` 当成场景候选，导致真正的场景 `酒店` 没有被优先匹配。

## 修改内容

- `frontend/src/store/jimengStore.ts` 将一次性全选的分镜 ID 拆成每 5 条一批，顺序调用匹配接口并合并返回结果。
- `backend/app/api/shots.py` 新增 `MATCH_ASSET_BATCH_SIZE = 5`，并让 `/jimeng/projects/{project_id}/shots/match_assets` 在单次请求内也按每 5 条分镜分批执行。
- 保持接口返回结构不变，用户仍然可以一次性全选，前端会自动分批提交。
- `backend/app/jimeng_matching.py` 新增场景上下文词过滤，忽略 `日`、`夜`、`白天`、`晚上`、`雨天`、`雪天`、`阴天`、`晴天` 等时间或光线词。
- 场景字段继续按结构化列表匹配，不会因为正文中出现泛化短词就误绑资产。
- 新增批处理单元测试，覆盖 12 条数据按 5、5、2 拆分。
- 新增场景匹配回归测试，覆盖 `场景：日，酒店` 应匹配 `酒店`，不匹配 `日`。
