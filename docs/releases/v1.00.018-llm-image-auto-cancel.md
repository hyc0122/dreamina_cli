# v1.00.018 大模型生图记录自动取消

- 更新时间：2026-06-21 00:55:35 +08:00
- 更新名称：大模型生图记录超过时长自动取消

## 更新内容

1. “生成记录 -> 大模型生图记录”新增“超过多久自动取消”选项。
2. 默认规则为超过 20 分钟仍未获取成功时自动取消继续获取。
3. 可选时间包括 10 分钟、20 分钟、30 分钟、1 小时、2 小时和不自动取消。
4. 自动取消规则会保存到浏览器本地设置，下次打开仍沿用上次选择。
5. 后端轮询接口新增 `auto_cancel_minutes` 参数，自动取消由后端在轮询前执行。
6. 被自动取消的记录会写入错误信息和反馈记录，后续不会继续自动获取。
7. “继续获取全部”和单条“继续获取”都会应用当前自动取消设置。

## 修复问题

1. 避免大模型任务长时间无结果时一直反复获取。
2. 避免远端无法完成或本地一直拿不到结果的任务长期占用待获取状态。

## 使用说明

1. 进入“生成记录 -> 大模型生图记录”。
2. 在筛选栏选择“超过多久自动取消”。
3. 页面自动轮询或点击“继续获取全部”时，会先检查记录提交时间。
4. 超过设定时间且仍未成功的记录会变为“已取消”。
5. 选择“不自动取消”后，系统不会按时长取消记录。
