# v1.00.007 根目录同步收尾与选中资产生图修复

- 更新时间：2026-06-20 18:57:50 +08:00
- 更新类型：功能同步 / Bug 修复 / 文档同步

## 更新概览

本次更新收尾同步历史沟通中仍残留在分支或旧文档里的功能点，重点修复资产抽屉、新建资产、批量生图、佳速 API 测试和视频时长边界。

## 功能调整

- 资产抽屉的生图设置改为读取资产管理全局图片模型、默认画幅和分辨率。
- 资产抽屉新建角色时支持选择“单人 / 群演”，不再按分镜序号猜测角色分类。
- 资产抽屉新建资产不再提交单独的 `image_model`，模型统一由全局生图模型决定。
- 资产管理页和资产抽屉批量生图都按已勾选资产执行，并按资产画幅分组传递对应 `size`。
- 导入资产描述示例移除 `image_model` 字段，避免误导为单个资产可独立选模型。

## Bug 修复

- 修复 `assetImageSizeFromSettings` 被引用但共享模块未导出的编译风险。
- 修复 LLM 批量生图和旧 CLI 批量生图在 `asset_ids` 为空时回退全量资产的问题，现在会直接提示先选择资产。
- 修复队列快照写入分镜默认时长时未钳制到 4-15 秒的问题。
- 同步佳速图片接口测试断言，确认请求体只包含 `model`、`prompt`、`params.size`、`params.quality`。
