# v1.00.015 大模型资产生图记录

- 更新时间：2026-06-20 23:26:24 +08:00
- 更新名称：大模型资产生图记录与继续获取

## 更新内容

1. 后端新增大模型资产生图记录文件，记录资产、供应商、模型、尺寸、提示词、task_id、远端状态、轮询次数、错误信息和反馈记录。
2. 资产纯文本生图成功后会把记录标记为已保存；如果同步等待超时但接口已返回 task_id，会保留记录并提示到生成记录页继续获取。
3. 新增大模型生图记录接口，支持列表查询、批量继续获取、单条继续获取、手动取消和手动删除。
4. 手动取消后的记录进入取消状态，不再参与自动继续获取；删除记录只删除记录本身，不删除已经保存到资产里的图片。
5. 生成记录页新增“大模型生图记录”页签，可按状态筛选，查看 task_id、进度、模型、尺寸、提示词、错误和最近反馈。
6. 记录页打开时会定时获取待完成任务，远端成功后自动下载图片并写回对应资产。
7. 单个资产生图提交后，如果返回的是远端任务记录，页面提示会显示 task_id，方便继续追踪。

## 修复问题

1. 修复大模型接口远端已经成功但本地请求超时后无法继续获取的问题。
2. 修复“未返回图片数据”这类终态异常缺少可追踪记录的问题。
3. 补齐大模型资产生图过程中的本地反馈记录，方便回溯每次继续获取结果。

## 使用说明

1. 在资产管理中点击单个资产 AI 生图或批量生图。
2. 如果图片立即生成成功，资产图片会直接保存。
3. 如果接口返回超时但已经拿到 task_id，进入“生成记录 -> 大模型生图记录”。
4. 点击“继续获取全部”或单条“继续获取”，系统会按记录中的 task_id 查询远端任务。
5. 不想继续查询某条任务时点击“取消”；需要清理历史时点击“删除”。
