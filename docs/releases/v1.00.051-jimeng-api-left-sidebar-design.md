# v1.00.051 - jimeng-api 接入与左侧工作台设计确认

更新时间：2026-06-25 21:59:10 +08:00

## 更新名称

jimeng-api 正式接入设计与左侧工作台 UI 改版草图

## 背景

当前项目已经尝试过“网页测试”和“JiMengHub”两条多账号/网页通道，但这两条链路会让主导航越来越复杂，也容易和官方 CLI 队列、正式生产流程混在一起。后续改为使用 `G:\漫剧\LumenX\dreamina_cli\jimeng-api` 作为正式参考来源，把可用能力接入当前项目。

## 设计结论

采用第二套草图方案：左侧工作台布局。

- 删除“网页测试”入口和相关测试链路。
- 删除“JiMengHub”入口和相关 provider/页面代码。
- 保留当前项目已有的剧本、资产、分镜、生成记录、队列能力。
- 新增正式“即梦 API”配置入口，用于管理 `jimeng-api` 通道。
- 官方 CLI 与即梦 API 分成两个清晰通道，不再混用名字。
- UI 改为左侧导航、顶部上下文栏、中央业务卡片的布局，接近参考项目的工作台结构，但不直接照搬业务模型。

## 接入边界

`jimeng-api` 只作为功能参考和本地服务通道，不把整个外部项目目录提交进当前仓库。

第一阶段接入重点：

- 视频生成：文生视频、图生视频、多参考素材模式。
- 模型映射：前端显示 `api-seedance2.0-fast` 等可识别名称，后端映射到 `jimeng-api` 实际模型名。
- 任务队列：当前队列继续统一调度，任务按模型或通道选择官方 CLI 或即梦 API。
- 账号/凭证：放到“即梦 API”配置页，不再使用“网页测试”概念。

第二阶段再整理：

- 图片生成、图生图、图片上传能力是否合并到资产生图流程。
- 失败重试、轮询、下载和本地保存是否完全复用当前队列记录。
- README 和使用说明中补充即梦 API 通道说明。
