# v1.00.014 资产生图类型前缀分类补齐

更新时间：2026-06-20 23:13:28 +08:00

## 更新名称

资产生图类型前缀分类补齐

## 问题背景

资产生图设置中，画风已经区分了单人角色和群演角色，但类型前缀仍然只有一套人物前缀。这样群演资产会和单人角色共用同一段前缀约束，不方便控制群演人物的生成重点。

## 修改内容

- 类型前缀中的人物前缀拆分为：
  - 单人角色提示词前缀
  - 群演角色提示词前缀
- “资产管理 -> 生图设置 -> 类型前缀”中，人物页会同时显示单人和群演两块前缀编辑区。
- 场景和道具前缀保持独立设置。
- 单个资产 AI 生图会按资产的“角色分类”选择单人或群演前缀。
- 批量资产生图也会按资产的“角色分类”分组，并使用对应前缀。
- 发送预览同步支持单人/群演前缀切换。
- 旧版本地设置中的“人物前缀”会自动迁移为“单人角色前缀”，群演使用新的独立默认前缀。

## 使用说明

1. 打开“资产管理 -> 生图设置”。
2. 切换到“类型前缀”页面。
3. 选择“角色”后，分别填写“单人角色前缀提示词”和“群演角色前缀提示词”。
4. 角色资产的“角色分类”为“群演”时，生图会使用群演角色前缀。

## 影响范围

- 影响资产管理中的单个资产 AI 生图。
- 影响资产管理中的批量生图。
- 影响资产生图设置的发送预览。
- 不影响分镜视频生成模板。
