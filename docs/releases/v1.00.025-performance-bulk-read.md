# v1.00.025 分镜编辑和大列表性能优化

- 更新时间：2026-06-21 10:03:37 +08:00
- 更新类型：体验优化 / 性能优化 / 后端查询优化

## 更新概述

本次修复重点处理分镜工作台“点击编辑提示词、保存提示词卡顿”和生成记录、资产管理、队列页的大列表加载问题。

## 分镜工作台

- 分镜提示词编辑区域现在会阻止点击事件冒泡，点击“编辑提示词”、双击提示词框、保存和取消时，不会再同时触发整条分镜的右侧预览切换。
- 保存分镜提示词后只更新当前分镜，不再调用全项目刷新。
- 保存后会清空当前分镜旧高亮，避免新提示词继续显示旧匹配范围。
- 提交分镜入队后，前端立即把对应分镜标记为 `queued`，工作台会立刻显示“视频制作中”，不再等待全项目刷新。

## 后端批量读取

- 新增 `GET /jimeng/projects/{project_id}/bindings`，支持一次按多个 `shot_ids` 返回分镜绑定，避免前端对每条分镜逐个请求绑定。
- 新增 `GET /jimeng/projects/{project_id}/candidates`，支持一次按多个 `shot_ids` 返回候选视频，并支持 `limit_per_shot` 限制单个分镜候选数量。
- 大模型生图记录列表 `GET /jimeng/llm/asset_image_records` 支持 `project_id`、`status`、`limit`、`offset`，返回 `total`、`limit`、`offset`，减少记录页全量读取压力。
- SQLite 增加资产、绑定、队列、候选视频和大模型生图记录相关索引。

## 生成记录

- 视频候选记录不再按每条分镜逐个请求候选视频，改为按项目批量请求。
- 大模型生图记录继续按提交时间排序，列表接口支持分页字段，后续可继续扩展前端分页。
- 图片缩略图增加懒加载和异步解码，降低打开记录页时的瞬时渲染压力。

## 资产管理

- 资产管理页刷新改为只拉项目和资产列表，不再连带刷新分镜、绑定、队列和提示词预设。
- 搜索输入使用延迟计算，输入时不会立即对全部资产重新过滤。
- 资产卡片图片增加懒加载和异步解码，资产卡片组件做 memo 包装，减少大资产列表重渲染压力。

## 队列页

- 队列页加载分镜名称时，只按当前页队列项涉及的项目加载分镜数据，减少大队列列表翻页和刷新时的无效请求。
