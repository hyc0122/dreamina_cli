# v1.00.029 资产角色分类导入导出格式完善

- 更新时间：2026-06-21 14:46:41 +08:00
- 更新类型：导入导出格式 / 文档同步

## 更新概述

本次修复资产导出格式中角色分类不够直观的问题。原来导出数据里的 `character_kind` 不够适合人眼阅读，用户需要自己理解对应关系。现在导出文件会直接显示中文“单人 / 群演”。

## 修改内容

- 资产管理导出 CSV 时新增中文列 `角色分类`。
- CSV 中 `character_kind` 仍然保留，继续用于再次导入和程序兼容。
- JSON 导出时为每个资产补充中文键 `角色分类`，角色资产显示 `单人` 或 `群演`，非角色资产为空。
- 导入资产描述弹窗的 JSON 示例新增 `character_kind`。
- 导入资产描述弹窗的 CSV 示例新增 `character_kind`，并增加单人角色和群演角色示例。
- 格式说明新增：`character_kind` 只用于角色，可填写“单人”或“群演”；CSV 也可以使用中文表头 `角色分类` 或 `人物分类`。
- `docs/使用说明.md` 同步更新资产导入导出格式说明。

## 影响范围

- 影响页面：资产管理、导入资产描述弹窗。
- 影响文件：导出的资产描述 JSON / CSV。
- 不改变数据库字段，仍使用 `character_kind` 保存角色分类。
- 不影响已有导入文件；旧格式没有 `character_kind` 时，后端仍按默认单人处理。
