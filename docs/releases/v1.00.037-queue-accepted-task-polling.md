# v1.00.037 即梦队列防重复提交修复

- 更新时间：2026-06-21 23:40:53 +08:00
- 更新类型：队列状态机 Bug 修复

## 修复背景

部分即梦 CLI 调用实际已经成功提交到远端，并返回了 `submit_id` 和 `querying` 状态，但本地封装层同时带有“提交返回错误”之类的错误提示。旧逻辑会优先根据 `error_message` 把队列项判为失败，再由失败策略自动重试，导致同一分镜被反复重新提交。

## 修改内容

- 调整 `JimengQueueWorker` 的结果判定顺序。
- 当结果包含 `submit_id`，且 `gen_status` 属于 `querying`、`running`、`pending`、`processing` 时，优先将队列项置为 `polling`。
- 对已接收任务清除本地提交错误提示，避免前端继续把该行显示为失败。
- 保留原始输出 `cli_raw_output`，方便后续排查本地封装层提示。
- 未拿到 `submit_id` 的提交失败仍按原失败策略处理。

## 验证

- 新增回归测试，覆盖“已返回 `submit_id` 但同时带本地提交错误”的场景。
- 已验证该场景不会进入 `retry_wait`，不会增加重试次数，也不会再次调用提交。
