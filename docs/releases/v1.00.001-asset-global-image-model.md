# v1.00.001 资产管理全局生图模型与设置拆分

更新时间：2026-06-20 11:22:36 +08:00

## 更新概要

本次更新把资产管理里的生图模型选择统一到全局设置中，并把“生图设置”弹窗拆成多个独立小页面模块，降低页面长度和文件复杂度。

## 详细内容

- 资产管理新增全局生图模型设置，使用大模型设置中的图片模型列表。
- 单个资产详情不再选择生图模型，只显示当前全局模型。
- 新建资产弹窗移除单资产生图模型选择，避免和全局设置冲突。
- 单张资产 AI 生图和批量资产生图统一使用资产管理全局模型。
- 新增 LLM 批量资产生图接口，复用现有单张 LLM 生图流程。
- “生图设置”弹窗拆为模型与尺寸、画风风格、类型前缀、风格库、发送预览等独立模块。
- README 只保留当前版本、最近更新概要和更新日志入口；详细更新内容写入 `docs/releases/`。

## 兼容说明

- 资产数据中的 `image_model` 字段继续保留，用于旧数据、导入导出和即梦 CLI 历史接口兼容。
- 旧即梦 CLI 资产图片生成接口不删除，避免破坏已有调用。
- `v1.00.001` 是项目展示版本号；Python/npm 包元数据不使用带前导零的展示版本，避免破坏包管理工具校验。

## 验证记录

- 前端构建：`npm run build`
- 本地结构测试：`node frontend/src/__tests__/asset-global-image-model.local.mjs`
