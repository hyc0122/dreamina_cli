# v1.00.054 新增剧本继承全文资产

- 更新时间：2026-06-26 11:34:18 +08:00
- 更新类型：剧本创建体验优化

## 修改内容

新建剧本时的继承逻辑从“只复制来源分镜已绑定资产”调整为“复制来源剧本全文资产库”。

现在选择来源剧本后，会把来源剧本中的角色、场景、道具、资产图片、角色音色、别名、描述、角色分类、生图模型、画幅和生图参数复制到新剧本。来源分镜只作为可选定位信息，不再限制复制范围。

## 不复制内容

本次继承不会复制旧分镜、旧分镜绑定关系、候选视频、队列任务和生成记录。新剧本导入分镜后，仍然通过分镜工作台的资产匹配功能重新建立当前剧本的绑定关系。

## 使用方式

在剧本列表创建新剧本时，选择“继承全文资产”的来源剧本即可。来源分镜可以不选；如果选择来源分镜，后端只校验它属于来源剧本，不会只复制该分镜绑定资产。
