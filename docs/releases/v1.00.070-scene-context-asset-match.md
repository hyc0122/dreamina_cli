# v1.00.070 场景上下文资产匹配修复

- 版本：v1.00.070
- 更新时间：2026-07-25 20:33:54 +08:00
- 更新类型：资产匹配错误修复

## 问题表现

同一份程序在开发电脑上可以匹配旧格式分镜，但其他电脑导入的新格式分镜无法匹配场景资产。角色仍可正常匹配。

典型场景字段：

```text
场景：外 北河第一纺织厂大门 冬至上午
人物：周向东、马成山
```

资产库中实际场景名称为 `北河第一纺织厂大门`。

## 原因

角色字段会按顿号拆分，因此角色名称可以独立匹配。场景字段此前按完整字段做严格匹配，把方位、场景名和时间说明一起当成一个名称，最终使用 `外北河第一纺织厂大门冬至上午` 查询资产，自然无法命中 `北河第一纺织厂大门`。

问题与分镜提示词总长度无关，也不是另一台电脑的资产数据损坏。

## 修改内容

1. 场景结构化解析新增 `内`、`外`、`内景`、`外景` 等场景上下文词识别。
2. 对空格分隔的场景字段保留原始完整候选，同时提取每个完整分段参与匹配。
3. 继续使用严格完整名称匹配，不把长场景名拆成任意短词，避免 `大门` 误匹配 `北河第一纺织厂大门`。
4. 新增回归测试，覆盖带方位和时间说明的场景字段、完整场景命中及短名称不误命中。

## 验证范围

- 场景名称严格匹配。
- 角色名称匹配不受影响。
- 选中分镜批量匹配仍按每 5 条分批执行。
- 分镜导入和资产导入回归测试。

## 使用说明

对方电脑需要安装或解压 `v1.00.070` 新安装包。旧版本 EXE 内仍然是旧匹配代码，仅更新项目数据或刷新浏览器不会覆盖程序代码。
