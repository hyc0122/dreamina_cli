# v1.00.023 分镜提交制作反馈修复

- 版本号：v1.00.023
- 更新时间：2026-06-21 08:06:59 +08:00
- 更新名称：分镜提交制作反馈修复

## 更新内容

1. 右侧“提交当前分镜”按钮在提交中改为“分镜制作中...”。
2. 右侧“提交当前分镜”按钮提交中显示旋转动画，避免看起来没有响应。
3. 左侧工具栏“批量提交”按钮在提交中同样改为“分镜制作中...”并显示旋转动画。
4. 右侧提交当前分镜时，如果校验失败，会在提交按钮旁直接显示错误。
5. 缺少角色、缺少场景、未选择分镜等错误不再只显示在左侧表格区域。

## 修复原因

右侧“提交当前分镜”会复用工作台的提交校验逻辑。原来校验失败时，错误只传给左侧分镜表格显示；用户只看右侧面板时，会感觉点击按钮后没有反应。

## 使用方式

1. 在分镜工作台选择一个分镜。
2. 点击右侧“提交当前分镜”。
3. 如果分镜可提交，按钮会进入“分镜制作中...”动画状态。
4. 如果分镜缺少角色或场景，错误会直接显示在右侧提交按钮下方。
5. 批量提交时，左侧工具栏按钮也会进入“分镜制作中...”动画状态。
