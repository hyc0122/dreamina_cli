# v1.00.021 资产批量选择和参考图复制优化

- 版本号：v1.00.021
- 更新时间：2026-06-21 06:44:49 +08:00
- 更新名称：全选未生图资产与风格参考图复制

## 更新内容

1. 资产管理页在“全选当前”和资产筛选区旁新增“全选未生图”按钮。
2. “全选未生图”只作用于当前资产分类和当前搜索筛选结果。
3. 未生图资产按本地资产图片为空判断；正在大模型生图中的资产不会被纳入默认选择，避免重复提交。
4. 已经全选未生图资产时，再次点击按钮会取消这些未生图资产的选中状态。
5. 批量生图仍然只按当前已勾选资产提交，不再在点击批量生图时自动选择资产。
6. 风格参考图列表新增“复制全部链接”按钮，复制结果按一行一个图片链接写入剪贴板。
7. 每张风格参考图右上角新增复制按钮，可直接复制单张参考图链接。

## 使用方式

1. 在资产管理选择角色、场景或道具分类。
2. 如有需要，先通过搜索框缩小资产范围。
3. 点击“全选未生图”，系统会勾选当前范围内没有本地图片且不在生图中的资产。
4. 点击“批量生图”，在弹窗中确认参数后提交。
5. 在“生图设置 -> 风格参考图”中，可以点击单张图片右上角复制按钮，也可以点击“复制全部链接”一次复制所有参考图链接。

## 修复和优化

1. 避免点击批量生图时隐式改变选择范围，让批量提交更可控。
2. 减少手动逐个勾选未生图资产的操作。
3. 让风格参考图链接更容易复制到外部文档或接口调试工具中。
