# v1.00.008 分镜工作台视频指令模板入口迁移

- 更新时间：2026-06-20 19:47:36 +08:00
- 更新类型：界面调整 / 文档同步

## 更新概览

本次更新把全局视频指令模板管理从“即梦设置”移到“分镜工作台”，入口放在“刷新项目数据”按钮左侧，让视频模板设置更靠近分镜提交工作流。

## 功能调整

- “即梦设置”页不再显示视频指令模板管理区域，只保留 CLI、登录、积分、全局视频提交参数和队列调度等设置。
- “分镜工作台”顶部新增“视频指令模板”按钮，位置紧邻“刷新项目数据”左侧。
- 点击“视频指令模板”后，在工作台顶部展开模板管理面板，可继续新建、编辑、保存并应用到当前项目。
- 展开区域增加最大高度和滚动，避免打开模板管理时过度挤压分镜列表。
