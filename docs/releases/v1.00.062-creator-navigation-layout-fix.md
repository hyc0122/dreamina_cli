# v1.00.062 创作助手导航和布局修复

- 更新时间：2026-06-26 18:53:40 +08:00
- 版本号：v1.00.062

## 更新名称

创作助手导航和赛博交互边界修复

## 修改内容

1. 外层左侧导航的大模块按钮新增独立样式标识，赛博主题下一级目录常态使用霓虹高亮。
2. 二级菜单和普通按钮的强霓虹效果改为鼠标悬停时触发，避免页面常态过亮。
3. 创作助手入口改为由主应用传入当前创作路由，保证点击外层“剧本项目 / 小说创作 / 剧本创作 / 15秒分镜稿创作 / 作品评测”时页面内容同步切换。
4. 创作助手首页移除内部重复一级侧栏，只保留外层统一导航；进入具体创作项目后仍显示项目流程步骤。
5. 创作助手和小说创作工作区增加高度与滚动边界，内容在主框架内滚动，不再把整体界面撑出屏幕。
