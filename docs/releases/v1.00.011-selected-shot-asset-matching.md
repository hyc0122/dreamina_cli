# v1.00.011 选中分镜资产匹配与删除

更新时间：2026-06-20 21:24:38 +08:00

## 更新名称

选中分镜资产匹配与删除

## 问题背景

分镜工作台原来的“匹配资产”会直接对当前项目全部分镜执行匹配。项目分镜较多时，这种全量操作容易误绑定不想处理的分镜，也不方便只处理局部修改后的分镜。

## 修改内容

- “匹配资产”改为“匹配选中资产”，必须先勾选分镜再执行。
- 需要全项目匹配时，先点击“全选分镜”，再点击“匹配选中资产”。
- 新增“删除匹配资产”按钮，用于批量删除选中分镜中的自动匹配资产绑定。
- 删除匹配资产时只删除 `source=auto` 的自动匹配绑定，手动添加的资产绑定不受影响。
- 后端匹配接口支持 `shot_ids`，只处理指定分镜。
- 后端新增清除自动匹配绑定接口，避免前端逐条删除造成状态不一致。
- 匹配完成后会提示命中数量和新增绑定数量。
- 删除完成后会提示实际删除的自动匹配绑定数量。

## 使用方式

1. 在分镜工作台勾选需要处理的分镜。
2. 点击“匹配选中资产”，只会对这些分镜执行资产匹配。
3. 如果需要清除这些分镜里的自动匹配资产，点击“删除匹配资产”。
4. 如果要处理全部分镜，先点击“全选分镜”。

## 影响范围

- 影响分镜工作台顶部工具栏。
- 影响分镜资产自动绑定和高亮状态。
- 不影响资产管理中的资产数据本体。
- 不影响手动添加到分镜里的资产绑定。
