# v1.00.034 分镜全文高亮修复

更新时间：2026-06-21 19:45:03 +08:00

## 更新名称

分镜全文高亮修复

## 修改内容

- 分镜提示词高亮改为全文命中，不再只在 `人物：`、`场景：` 等字段里显示亮色。
- 已绑定的人物、场景、道具在剧情正文、动作描述、对白等位置重复出现时，都会显示对应颜色。
- 允许同一个已绑定资产在同一条分镜提示词中多次高亮。
- 保留非重叠高亮规则，避免别名和长短名称重叠时出现重复嵌套。
- 继续保留完整人物名匹配规则：`沈云禾[年轻时期]` 可以匹配 `沈云禾(年轻时期)`，但裸名 `沈云禾` 不会误匹配带括号状态的人物。

## 影响范围

- 分镜工作台提示词高亮显示。
- 资产匹配或手动绑定后的全文提示词预览。

- `npm test`
