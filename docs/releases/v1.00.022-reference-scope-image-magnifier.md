# v1.00.022 参考图使用范围与详情图悬停放大

- 版本号：v1.00.022
- 更新时间：2026-06-21 07:50:17 +08:00
- 更新名称：参考图使用范围与详情图悬停放大

## 更新内容

1. 资产生图设置的“风格参考图”旁新增“角色使用”和“场景使用”两个开关。
2. 两个开关默认不勾选；即使已经上传风格参考图，默认也不会传入生图请求。
3. 单个角色资产生图时，只有勾选“角色使用”才会传风格参考图。
4. 单个场景资产生图时，只有勾选“场景使用”才会传风格参考图。
5. 道具资产生图暂不使用风格参考图，保持为空。
6. 批量生图和单个生图使用同一套参考图范围判断，避免参数不一致。
7. 资产管理右侧详情图片新增“图片悬停放大”开关。
8. 打开放大开关后，鼠标移动到右侧当前资产图片上，会显示跟随鼠标的放大预览；鼠标离开图片范围后自动隐藏。

## 使用方式

1. 打开“资产管理 -> 生图设置 -> 风格参考图”。
2. 上传或保留已有风格参考图。
3. 按需要勾选“角色使用”或“场景使用”，不勾选的类型在生图时不会传参考图。
4. 在资产详情右侧打开“图片悬停放大”的“放大开关”。
5. 鼠标放到右侧资产图片上查看放大预览，移出图片区域后预览会自动消失。

## 修复和优化

1. 避免风格参考图一旦上传就默认影响所有资产生图。
2. 让角色、场景的参考图使用范围更可控。
3. 增加右侧资产图片快速查看细节的交互，不需要每次打开全屏预览。
