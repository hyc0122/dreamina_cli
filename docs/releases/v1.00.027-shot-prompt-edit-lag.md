# v1.00.027 分镜提示词编辑卡顿优化

- 更新时间：2026-06-21 12:34:20 +08:00
- 更新类型：体验优化 / 前端性能优化

## 更新概述

本次只针对分镜工作台里提示词编辑区的交互卡顿：双击提示词框进入编辑、点击取消、点击确认保存时，减少大分镜项目中的无效重绘和浏览器布局计算。

## 修复内容

- `ShotPromptCell` 增加 `memo` 比较逻辑，父级刷新时，如果当前分镜提示词和高亮数据没有变化，不再重绘提示词单元格。
- 提示词编辑、取消和打开编辑器的事件处理改为稳定回调，减少不必要的函数重建。
- 分镜卡片启用 `content-visibility: auto` 和 `contain-intrinsic-size`，让浏览器跳过屏幕外分镜卡片的布局与绘制。
- 空绑定和空高亮数组改为复用常量，避免父级渲染时给子组件传入新的空数组，导致 memo 失效。
- 编辑提示文案改为“只保存当前分镜提示词”，避免继续误解为全量刷新。

## 影响范围

- 影响页面：分镜工作台。
- 重点场景：300 条左右的大分镜项目中，操作第一屏提示词编辑区时，屏幕外分镜不再参与同一次布局计算。
- 不改变提示词保存接口、不改变资产绑定、不改变视频提交逻辑。
