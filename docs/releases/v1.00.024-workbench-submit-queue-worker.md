# v1.00.024 分镜提交入队和 worker 状态提示优化

更新时间：2026-06-21 08:43:49 +08:00

## 更新名称

分镜提交入队和 worker 状态提示优化

## 功能调整

- 分镜工作台顶部“参数设置”入口改为“批量提交”。
- “批量提交”弹窗中同时确认本次视频参数、提交间隔，并点击“开始批量提交”写入队列。
- 批量提交有勾选分镜时提交勾选项；没有勾选时默认提交当前项目全部分镜。
- 单个分镜或批量分镜提交成功后，前端会自动调用队列启动接口，打开即梦队列开关。
- 分镜进入队列后，工作台把 `queued` 和 `running` 状态统一显示为“视频制作中”。
- 单个分镜已经排队或运行时，右侧“提交当前分镜”按钮禁用并显示“视频制作中...”，避免重复提交。

## Bug 修复

- 移除提交前“缺少道具”等资产类型齐全校验，不再要求角色、场景、道具三类都绑定。
- 提交前只要求目标分镜至少有一个已绑定资产带本地图片；有图片即可提交给即梦全能参考流程。
- 自动开启队列失败或 worker 离线时，工作台会弹窗提示，不再让用户误以为点击没有反应。

## worker 提示规则

- 提交成功后会自动开启队列开关。
- 如果没有检测到独立 worker 在线心跳，会弹窗提示：
  - 分镜已经进入本地队列。
  - 队列开关已经打开。
  - 需要进入顶部导航“即梦排队”，在状态区点击“启动 worker”。
- 如果自动开启队列接口失败，也会弹窗提示到“即梦排队”页面手动点击“开始队列”和“启动 worker”。

## 影响范围

- 前端分镜工作台提交链路。
- 分镜工作台顶部批量提交入口。
- 分镜工作台状态展示和右侧单分镜提交按钮。
- 不改变后端队列 worker 的提交间隔、轮询、重试和失败策略。
