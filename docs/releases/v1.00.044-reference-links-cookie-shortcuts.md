# v1.00.044 风格参考图外链与 Cookie 辅助优化

更新时间：2026-06-23 01:39:54 +08:00

## 更新名称

风格参考图外链预览与网页测试 Cookie 辅助

## 剧本功能和体验优化

- 资产生图设置的“风格参考图”页新增手动图片链接输入，上传图片和外链共同进入“已获取链接”列表。
- 参考图列表统一支持小图预览、单张复制、全部复制、删除和点击/悬停居中放大展示。
- 外链不做提前下载校验，只交给浏览器图片加载判断是否可预览，避免保存设置时卡顿。
- 上传图片和手动外链共同限制最多 10 张，超过数量会提示跳过。
- 网页测试账号池新增“打开即梦获取 Cookie”按钮，可直接打开即梦生成页。
- 网页测试账号池新增“Cookie 复制教程”弹窗，说明从开发者工具 Network 请求头复制完整 Cookie 的方法。
- Cookie 输入区新增“粘贴 Cookie”按钮，支持从剪贴板填入完整 Cookie 或 sessionid。
- 粘贴后会在前端提示是否缺少 ttwid、odin_tt、user_spaces_idc，后端保存后仍会继续做最终缺失项判断。

## Bug 修复

- 修复风格参考图只能通过上传获得链接的问题，支持直接使用已有图片 URL。
- 避免用户误以为工具可以跨站一键读取即梦登录 Cookie，教程中明确说明浏览器安全策略和 HttpOnly 限制。

## 影响范围

- 前端：资产生图设置弹窗、网页测试页、即梦 UI helper 测试。
- 后端：无新增接口。
- 数据：不修改已有项目数据结构。
