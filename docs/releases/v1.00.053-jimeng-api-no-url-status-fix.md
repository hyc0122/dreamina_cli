# v1.00.053 - 队列在途状态误判修复

更新时间：2026-06-25 22:39:59 +08:00

## 更新名称

队列在途状态误判修复

## 修改内容

- 修复 `jimeng-api` 响应中只有 `submit_id`、没有视频 URL 时仍被视为正常在途的问题。
- `jimeng-api` 通道现在要求响应里能解析到视频 URL；如果没有 URL，会标记为失败，并提示检查 `jimeng-api` 服务日志或即梦账号是否实际创建任务。
- 前端队列状态判断改为错误优先：如果队列项存在错误、失败状态或失败输出，不再因为存在 `submit_id` 就显示“在途中”。

## 影响范围

- 只影响 `jimeng_api` 通道和队列状态展示。
- 官方 CLI 正常提交、轮询和下载逻辑不受影响。

## 验证

- 已执行 `npm run build`。
- 已执行 `python -m compileall backend/app`。
