# v1.00.057 创作助手原布局接入大模型

- 更新时间：2026-06-26 14:01:31 +08:00
- 更新名称：创作助手原布局接入大模型

## 修改内容

- 新增“创作助手”入口，嵌入 `script-creator` 原项目的页面结构和交互流程。
- 保留创作助手原来的项目首页、全局设置、小说创作、剧本创作、15秒分镜稿创作、作品评测和项目内工作台布局。
- 删除早期手写的简化创作助手实现，避免出现两套创作流程和两套布局。
- 创作助手的大模型请求统一接入当前项目后端 `/jimeng/creator/chat/fallback`，继续保留原项目的首选模型、备用模型 1、备用模型 2 和超时切换逻辑。
- 创作助手“全局设置”页只保留模型策略，不再填写独立 API Key；文本模型列表来自当前项目“大模型设置”里已启用的模型。
- 前端入口加载创作助手原项目 CSS，确保作为当前项目子模块运行时仍保持原布局样式。
- 后端新增创作助手模型列表和 fallback 聊天代理接口，由当前项目的大模型配置负责鉴权和请求。
