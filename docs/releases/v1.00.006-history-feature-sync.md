# v1.00.006 历史功能同步与角色分类完善

- 更新时间：2026-06-20 15:50:52 +08:00
- 更新类型：功能同步、数据结构完善、交互修复

## 本次同步范围

### 角色单人/群演分类

- 角色资产增加 `single`（单人）和 `group`（群演）分类。
- 新建、编辑、批量导入、项目复制、数据库迁移、队列资产快照均保留角色分类。
- 资产卡片、选择器、搜索和 CSV 导出显示或包含角色分类。
- 非角色资产自动使用 `single` 兼容值，不影响场景和道具数据。

### 资产画风与提示词

- 删除资产操作侧“全局提示词”的旧概念，迁移为“全局画风”。
- 支持全局画风、单人角色画风、群演角色画风和场景画风。
- 角色生图根据单人/群演分类自动组合对应画风。
- 生图提示词会清理 `【标签】` 形式的独立标题，不再把多余标签发送给模型。
- 旧 `imagePromptTemplate` 本地配置会自动迁移到全局画风，避免历史设置丢失。

### 全局生图模型

- 资产生图设置增加全局图片模型选择，模型来源与“大模型设置”中的图片模型同步。
- 单个资产不再单独选择图片模型，只显示当前全局模型及设置入口。
- 批量生图和单资产生图使用同一个全局模型。
- 大模型页面中的资产图片默认项明确为接口兜底画风，不与资产管理操作侧画风重复。

### 批量生图

- 批量生图继续只处理当前资产类型中已勾选的资产。
- 批量生图切换到 LLM 批量接口。
- 角色批量生图会按单人/群演拆分请求，分别组合对应画风。
- 后端批量接口支持 `asset_ids` 和 `asset_type`，不会回退为全部资产生成。
- 保留佳速 API 图片模型校验、异步结果轮询及请求参数规则。

### 生图设置模块化

- 资产生图设置弹窗拆分为模型与尺寸、画风设置、类型前缀、风格库、发送预览五个独立页面模块。
- 总弹窗只负责页面切换、保存和数据协调，降低单文件体积。
- 发送预览显示最终组合结果，便于检查实际发送内容。

### 视频时长

- 分镜单项设置、批量参数设置和即梦全局默认时长统一改为 4–15 秒下拉选择。
- 前端共享同一组选项，提交前统一钳制到 4–15 秒。
- 后端分镜更新、项目默认设置和队列生成快照同步执行时长钳制。

## 保留的根目录新功能

- 佳速 API 默认模型 `gpt-image-2` 及旧配置迁移。
- 佳速图片请求仅发送 `size` 和 `quality`。
- 队列独立 Worker、启动接口、生成记录和队列页面现有改动。
- 资产详情右栏紧凑布局。
- 批量生图按勾选资产执行。
