# v1.00.031 候选默认视频与居中放大预览

更新时间：2026-06-21 17:19:14 +08:00

## 更新概要

- 分镜右侧候选视频卡片新增“设为默认”按钮，用户可以明确指定本条分镜最终要导出的候选视频。
- “下载默认视频”只导出当前分镜的默认候选，生成记录页的单个下载也统一取同分镜默认候选，避免误把临时预览中的候选下载出去。
- 分镜工作台批量下载提示改为“默认视频”，后端仍按每条分镜的默认候选导出；没有默认候选的分镜会被跳过并提示数量。
- 资产管理右侧图片放大和分镜工作台资产抽屉悬停放大统一改为屏幕正中央展示，不再跟随鼠标或贴在列表右侧。

## 修改内容

- 新增 `AssetCenteredPreview` 组件，统一承载资产图片的居中大图预览。
- 资产管理详情图的放大开关保留，开启后鼠标移入图片区域才显示居中大图，移出后自动隐藏。
- 分镜工作台资产选择抽屉改为通过当前悬停资产 ID 渲染居中预览，避免原先行内绝对定位被滚动容器裁切。
- 分镜详情候选视频卡片拆分为预览按钮和默认按钮，避免按钮嵌套并保留候选预览能力。
- 单个视频导出入口从当前预览候选切换为默认候选，按钮文案同步为“下载默认视频”。
- 生成记录页的视频候选下载按钮改为“下载默认”，点击任意候选时都会下载该分镜默认候选；没有默认候选时提示先设置默认。

## 使用说明

- 在分镜右侧“候选视频”区域，点击候选卡片可以预览，点击“设为默认”可以把该候选设为默认视频。
- 点击“下载默认视频”或生成记录里的“下载默认”时，只会下载带默认标记的候选视频。
- 批量下载视频素材时，只会导出每个选中分镜的默认视频；没有默认视频的分镜不会导出。
- 资产管理中需要先打开“图片悬停放大”的放大开关，鼠标移到右侧资产图片上会在屏幕中央显示大图。
- 分镜工作台选择资产时，鼠标悬停资产列表项会直接在屏幕中央显示资产大图。
