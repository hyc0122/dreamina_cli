# v1.00.041 网页 SessionID 旧账号 Cookie 回填修复

更新时间：2026-06-23 00:16:21 +08:00

## 更新名称

网页 SessionID 旧账号列表回填 Cookie 指纹

## 修改内容

- 修复旧账号在“网页测试”页面仍显示 `Cookie: 1 个 · 缺少指纹` 的问题。
- 账号列表接口 `/jimeng/web-session/accounts` 读取旧账号时，会自动补齐 `_tea_web_id`、`s_v_web_id`、`fpk1`、`uifid`、`uifid_temp` 和 `x-web-secsdk-uid`。
- 账号详情读取也使用同一套回填逻辑，避免列表、提交、轮询三个入口状态不一致。
- 回填后的完整 Cookie JSON 会写回本地 SQLite，后续刷新页面会直接显示已补指纹。
- 旧版本创建过的 `web_session_accounts` 表会在启动时自动补齐 `cookie_json` 字段，避免账号列表接口因为缺字段返回 500。

## 影响范围

- 只影响“网页测试”页面和 `/jimeng/web-session/*` 独立测试接口。
- 不影响官方即梦 CLI 队列和分镜工作台正常提交。
- 已经存在的旧账号会在刷新账号列表时自动补齐，不需要重新添加账号。

## 验证重点

- 打开“网页测试”页面后，旧账号应显示 `Cookie: 7 个` 或更多，并显示“已补指纹”。
- 如果页面仍显示旧状态，需要重启当前运行中的后端服务，因为 Python 服务不会自动加载新代码。
