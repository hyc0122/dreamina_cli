# v1.00.061 赛博朋克组件皮肤增强

更新时间：2026-06-26 18:15:33 +08:00

## 更新名称

赛博朋克组件皮肤增强

## 修改背景

上一版已经把默认主题切换到赛博朋克，并把主题变量集中到 `frontend/src/styles/themes/app-themes.css`。但实际页面更像普通深色换色，没有达到演示模块里的机甲边框、切角、光条和霓虹层级效果。

## 修改内容

- 新增 `frontend/src/styles/themes/cyberpunk-components.css`，专门负责赛博朋克组件视觉层。
- `app-themes.css` 继续只维护深色、浅色、赛博三套颜色 token，避免业务模块分散写主题代码。
- index.css 统一引入主题 token 和赛博组件皮肤，所有模块默认共用同一套全局效果。
- 赛博主题下强化面板、侧栏、头部、卡片、表格、输入框、按钮和 hover 状态的霓虹视觉。
- 增加机甲式切角、边框光线、右上角光条、背景网格和扫描光，让实际页面更接近前面确认过的演示效果。

## 影响范围

- 前端全局主题样式。
- 主要影响当前默认的赛博朋克主题。
- 深色和浅色主题继续走原有变量，不额外套用赛博组件皮肤。
