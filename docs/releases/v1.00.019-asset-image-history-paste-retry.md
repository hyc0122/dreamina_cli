# v1.00.019 资产图片交互和生图记录续取优化

- 更新时间：2026-06-21 01:24:26 +08:00
- 更新名称：资产图片交互和生图记录续取优化

## 更新内容

- 资产详情图片右上角新增剪贴板粘贴按钮，复制图片后可一键上传并替换当前资产图。
- 资产图片放大预览改为全屏显示，黑底展示图片，保留关闭和新窗口打开按钮。
- 单个资产图片下方新增历史生成图区域，用于对比历史 AI 生图结果。
- 历史生成图支持“使用此图”，可把某次历史生成结果恢复为当前资产图。
- 大模型生图记录新增“手动获取选中”，可对选中的失败、已取消或待获取记录重新按 task_id 查询远端结果。
- 大模型生图结果图下载遇到 HTTP 403 时，会使用浏览器常见请求头重试，减少 CDN 拦截导致的本地保存失败。
- 分镜工作台的视频指令模板改为弹窗设置，不再以内嵌展开区域撑长工作台。

## 修复问题

- 修复大模型远端任务已经成功但结果图下载 403 后，用户无法方便手动继续获取的问题。
- 修复资产图片放大后仍像普通弹窗、无法充分利用屏幕的问题。
- 修复资产多次生图后缺少历史图对比和回退入口的问题。

## 使用说明

- 在资产管理右侧详情图右上角点击粘贴按钮，可读取剪贴板图片并上传。
- 在资产详情的“历史生成图对比”中点击图片可打开对比，点击“使用此图”可恢复为当前资产图片。
- 在“生成记录 -> 大模型生图记录”勾选失败、已取消或待获取记录后，点击“手动获取选中”可再次尝试获取远端图片。
- 在分镜工作台点击“视频指令模板”会打开弹窗管理模板。
