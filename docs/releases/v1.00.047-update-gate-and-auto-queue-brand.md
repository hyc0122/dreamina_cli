# v1.00.047 云端版本强制更新与品牌同步

更新时间：2026-06-24 23:47:19 +08:00

## 更新名称

云端版本强制更新与自动排队助手品牌同步

## 修改内容

- 项目显示名称统一为“即梦cli自动排队助手”，覆盖前端标题、首页、启动管理器、打包脚本默认 AppName 和项目元数据。
- 后端新增 `/app/version` 版本检测接口，当前版本优先读取 README；云端版本默认读取 `https://version.j11.net/`，支持 JSON 和 HTML 中的 `"version": "v1.00.047"` 写法。
- 前端启动时先检查云端版本；如果云端版本与当前版本不同，主界面不再打开，改为显示强制更新提示，并自动打开使用说明链接。
- 原生启动器显示当前版本和微信客服 `jmqh888`；如果检测到云端版本不一致，点击“打开软件”会跳转使用说明，不再进入前端。
- 网页测试页加入红色醒目提示：该功能内测中，仅用于测试，不建议作为正式生产通道。
- 大模型设置页面删除“接口未完全适配”红色提示，相关模型下拉和即梦设置说明也不再显示“未完全适配”字样。
- 即梦队列页从“手动提交队列”改为“自动提交排队”，按钮文案改为“恢复自动提交 / 暂停自动提交”，说明提交后的分镜由在线 worker 自动下发给即梦。
- 分镜工作台的队列启动失败提示和使用说明同步改为“恢复自动提交 / 暂停自动提交”，不再引导用户寻找“开始队列”。
- 打包脚本的默认应用名改为 ASCII 安全的 Base64 解码方式，避免 Windows PowerShell 读取无 BOM 脚本时把中文安装包目录名生成乱码。

## 云端版本号页面要求

当前默认版本源：

```text
https://version.j11.net/
```

页面中只要能被识别到版本号即可，例如：

```html
<li>"version": "v1.00.047"</li>
```

也可以使用 JSON：

```json
{
  "version": "v1.00.047",
  "url": "https://my.feishu.cn/docx/AfO9d2Gd0ovLpLxpeN2cjm1xnF2?from=from_copylink"
}
```

如果服务器版本号改成新版本，旧客户端会被拦截，并自动跳转到使用说明链接。

## 影响范围

- 后端版本检测接口和健康信息。
- 前端总入口、启动页、网页测试页、大模型设置页、队列页。
- 原生 Tkinter 启动器。
- README、CHANGELOG、打包脚本和包版本号。
