## 更新名称

README 界面预览补充

## 更新目的

本次更新把项目界面截图纳入仓库，并在 README 中使用 GitHub 可识别的相对路径展示图片，方便从仓库首页直接了解工具界面。

## 修改内容

- `img/` 目录改为需要上传的项目展示资源。
- README 新增“界面预览”章节。
- README 使用 `img/文件名.png` 相对路径引用图片，不使用本地磁盘路径。
- 展示页面包括：
  - 剧本列表
  - 分镜工作台
  - 资产管理
  - 即梦 CLI 设置界面
  - 即梦排队列表
  - 即梦生成视频记录

## 注意事项

- README 中的图片路径必须保持相对路径，避免写入本地绝对地址。
- 后续新增界面截图时，应优先放入 `img/` 目录，并在 README 或对应文档中用相对路径引用。
