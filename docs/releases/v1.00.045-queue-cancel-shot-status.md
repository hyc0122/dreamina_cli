# v1.00.045 即梦队列取消状态同步修复

- 更新时间：2026-06-23 23:42:42 +08:00
- 更新名称：即梦队列取消状态同步修复

## 修复内容

- 修复后台队列记录已经取消，但分镜工作台右侧仍显示“视频制作中”的问题。
- 取消队列任务时，后端会同步检查对应分镜是否还有其它等待、提交中、运行中或轮询中的队列任务。
- 如果还有其它活跃队列任务，分镜继续保持排队中或运行中，避免误改状态。
- 如果没有其它活跃任务，分镜会按候选视频恢复状态：
  - 已有默认候选视频或任意候选视频：恢复为已完成。
  - 没有候选视频：恢复为草稿。
- 前端在取消队列任务后会重新加载当前项目数据，确保工作台、右侧视频预览和提交按钮立即显示最新状态。

## 影响范围

- 即梦排队列表：取消队列任务后同步分镜状态。
- 分镜工作台：右侧“提交当前分镜”按钮状态跟随最新分镜状态刷新。
- 候选视频：取消不会删除已生成候选视频，只修正分镜状态。
