# v1.00.063 版本更新策略和创作助手导航修复

更新时间：2026-06-26 19:42:01 +08:00

## 更新名称

版本更新策略和创作助手导航修复

## 修改内容

1. 后端版本检测新增版本线判断：云端版本与本地版本不同会返回 `update_available=true`，用于提示发现新版本。
2. 只有 `major.minor` 版本线变化时才返回 `update_required=true`，用于强制更新拦截。
3. 本地 `v1.00.062` 到云端 `v1.00.063` 属于补丁更新，只提示不强制；本地 `v1.00.062` 到云端 `v1.01.001` 或 `v2.00.001` 属于版本线变化，会强制更新。
4. 前端和启动器继续读取 `update_required`，不需要大改 UI。
5. 赛博主题移除对所有 `bg-primary` 按钮的全局强制高亮，避免二级菜单默认全部变成亮色。
6. 创作助手外层二级菜单点击后会通知内部创作模块退出当前项目页，点击“剧本项目、小说创作、剧本创作、15秒分镜稿创作、作品评测”等入口时会回到对应入口界面。

## 验证要点

- `v1.00.062 -> v1.00.063`：提示更新，但不强制拦截。
- `v1.00.062 -> v1.01.001`：强制更新。
- `v1.00.062 -> v2.00.001`：强制更新。
- 赛博风格下，左侧二级菜单默认不应全部是亮色。
- 在创作助手内部打开某个项目后，点击外层二级菜单应退出项目并显示对应入口。
