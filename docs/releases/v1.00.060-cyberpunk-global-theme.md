# v1.00.060 全局赛博朋克默认风格

更新时间：2026-06-26 17:50:01 +08:00

## 更新名称

全局赛博朋克默认风格与主题集中管理

## 修改内容

- 新增 `cyber` 主题，并将本次升级后的首次打开默认主题切换为赛博朋克风格。
- 保留深色和浅色主题按钮，用户手动切换后仍会记住选择。
- 将全局主题 token、深色/浅色/赛博变量和赛博皮肤效果集中到 `frontend/src/styles/themes/app-themes.css`。
- 新增 `frontend/src/styles/themes/README.md`，说明以后全局风格统一从主题目录维护，避免每个模块零散写样式。
- 将 Tailwind 的 `primary`、`secondary`、`accent` 从硬编码颜色改为 CSS 变量，让所有模块跟随当前主题统一变色。
- 赛博主题统一覆盖页面背景、面板、侧栏、顶部栏、按钮、链接、输入框、表格、滚动条、标题和选中态的蓝紫霓虹效果。

## 使用影响

- 打开软件后，默认看到的是赛博朋克风格。
- 旧的业务页面不用逐个改布局，也会通过全局变量和通用选择器获得统一皮肤。
- 后续如果继续调整全局视觉，只需要优先修改 `frontend/src/styles/themes/app-themes.css`。
