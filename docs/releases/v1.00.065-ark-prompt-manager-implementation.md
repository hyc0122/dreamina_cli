# v1.00.065 火山方舟与提示词管理模块接入

更新时间：2026-06-27 04:09:48 +08:00

## 更新概要

本次把火山方舟接入到现有“大模型设置”和分镜提交链路，并新增独立“提示词管理”模块。提示词管理只负责模板维护和完整提示词组合，不调用大模型，也不与漫剧项目数据混用数据库。

## 主要修改

- 大模型设置新增 `火山方舟` 供应商类型，可配置 API Key、请求地址、文本模型和视频模型。
- 文本推理接入火山方舟 `/api/v3/chat/completions`，继续复用现有大模型调用入口。
- 文生视频新增火山方舟 provider，分镜视频模型选择到方舟模型后，队列 worker 会按方舟接口提交和轮询任务。
- 官方 CLI 视频生成链路保持不变，默认仍使用官方 CLI。
- 新增“提示词管理”独立模块，左侧按模板类型切换，右侧编辑模板内容并生成完整提示词。
- 提示词模板区分官方、用户和 VIP 来源；官方和 VIP 模板默认不可直接修改，可复制为用户模板后编辑。
- 提示词库使用独立 SQLite：`runtime_data/prompt_manager/prompt_manager.sqlite3`，不和剧本、资产、队列数据库混在一起。
- 前端新增提示词管理页面和 API 封装，后端新增提示词模板 CRUD、复制和完整提示词组合接口。

## 注意事项

- 火山方舟文生视频当前按纯文本提交实现；带本地参考图、参考视频的分镜仍应使用官方 CLI 通道。
- 云端提示词同步本次仍是设计预留，没有把本地模板自动上传到云端服务。
- 火山方舟供应商默认关闭，需要在“大模型设置”里配置 Key 并启用后才会出现在分镜视频模型选择中。

- 新增火山方舟文生视频 provider 单元测试。
- 新增提示词管理存储和 API 测试。
- 新增提示词管理前端结构检查。
